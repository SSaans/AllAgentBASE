# WechatMSG 项目需求文档（BRD）

## 一、项目概述

**项目名称**：WechatMSG  
**项目定位**：微信聊天记录导出与管理工具（维护型项目，使用现成开源方案）  
**当前状态**：立项阶段，待调研现有方案  

## 二、核心需求

### 2.1 功能需求

1. **微信聊天记录导出**
   - 提取微信本地数据库中的聊天记录
   - 支持文字、图片、视频、文件等多种消息类型
   - 保持原始消息格式与时间戳

2. **数据格式化输出**
   - 导出为可读格式（HTML、TXT、JSON 等）
   - 支持按联系人、群聊、时间范围筛选导出
   - 保留消息上下文与关联关系

3. **隐私与安全**
   - 本地处理，不上传数据到云端
   - 支持敏感信息脱敏
   - 符合数据安全规范

### 2.2 技术方案

**采用现成开源方案**：待调研确认具体项目（如 WeChatMsg、WechatExporter 等）

**技术栈（待确认）**：
- 语言：Python / C++ / Go（视具体方案而定）
- 数据库：SQLite（微信本地数据库格式）
- 界面：GUI / CLI（视方案而定）

## 三、验收标准

### 3.1 功能验收
- [ ] 能成功读取微信本地数据库
- [ ] 能正确解析各类消息类型
- [ ] 导出文件格式正确、可读
- [ ] 处理速度在可接受范围内

### 3.2 安全验收
- [ ] 数据处理全程在本地
- [ ] 无数据泄露风险
- [ ] 敏感信息可正确脱敏

## 四、非功能需求

- **易用性**：操作简单，文档清晰
- **稳定性**：不崩溃，能处理大量数据
- **兼容性**：支持主流微信版本
