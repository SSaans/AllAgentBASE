# WechatMSG - 微信聊天记录导出工具

## 项目简介

WechatMSG 是一个微信聊天记录导出与管理工具，用于提取、格式化和保存微信本地聊天记录。

**项目特点**：
- 本地处理，保护隐私
- 支持多种消息类型
- 导出格式可读
- 基于成熟开源方案
