# 规格变更：停止边界

## Purpose

规定监督功能在什么情况下必须停下，避免出现用户已经不用了它还在动的情况。

## ADDED Requirements

### Requirement: 用户忙时不打扰

系统 SHALL 在检测到用户正在通话、播放语音或主动交互时暂停提醒。

#### Scenario: 正在语音通话

- **WHEN** 用户处于通话或语音播放状态
- **THEN** 系统不弹提醒，等状态结束后再判断

### Requirement: 关掉就是关掉

系统 SHALL 在用户关闭监督开关后立即停止全部识屏与提醒。

#### Scenario: 关掉开关后观察

- **WHEN** 用户关闭监督开关
- **THEN** 之后不再有任何识屏动作，日志无新增

#### Scenario: 重启后不自动恢复

- **WHEN** 用户关掉开关后重启桌宠
- **THEN** 开关保持关闭状态，不自作主张打开
