# ALLSkill — 使用说明

> AllAgentBASE 的技能进货口。到外部技能市场找现成的技能，评估、选型、引进，沉淀进本仓库 `skill/`。

## 这个项目干什么

平台的子项目越来越多，每遇到一块「别人可能已经做成技能了」的活，就得重新搜一遍、重新判断一遍。这个项目把这件事收口到一处：去哪儿找、按什么打分、什么门槛才引进，都固定下来写进 `BRD.md`。以后每来一个新方向，照流程走一遍就行。

## 找技能的工具链

本机装了四个技能发现工具，找现成技能时按固定顺序跑，不用每次重想从哪儿找。四个工具的完整留档在 `skill/技能发现/`，调用顺序与命令见那里的 `README.md`。

| 顺序 | 工具 | 查哪儿 | 什么时候用 |
|---|---|---|---|
| 1 | `find-skills-vercel` | skills.sh（Vercel 索引） | 默认入口 |
| 2 | `find-skill-skillhub` | skillhub.cn 公开接口 | 第 1 项结果不足或不贴题 |
| 3 | `find-skills-agentspace` | skills.sh + ClawHub + GitHub 三源联合 | 需要跨源补充，或有候选要核实 |
| 4 | `find-skill-zqc` | 装前查（权限、外联、作者信誉） | 补充检索，或要评估候选安全 |

**怎么走。** 先看本机已装的技能够不够；不够从第 1 项往下，前一项结果不足、不相关或不可用才进下一项。已经够用就停，不必每次全跑。用户点名来源就直接用那一个。

**四条边界。** 只读检索，不上传本地内容，只发任务关键词；找技能不等于授权安装；第三方安全评级只作旁证，仍要看候选原文与依赖；「没有结果」和「接口故障」要分开报。

### 2026-10-12 四源实跑记录

用「绘画 / drawing / 美术 / 绘画点评 / drawing tutor」等词把四个源都跑了一遍。

| 源 | 状态 | 结果 |
|---|---|---|
| skills.sh（第 1 项） | 可用 | 命中偏工程向，GSAP 动画、电路图等，不贴绘画指导主题 |
| SkillHub（第 2 项） | 可用 | 命中多个贴题候选，本批引进即出自这里 |
| ClawHub / GitHub（第 3 项） | 可用 | ClawHub 返回零结果（真零结果，非故障）；GitHub 命中 `jlu45/drawing-error-tutor` 等低热仓库 |

结论是第 1 项对这个主题不敏感，第 2 项最好用，第 4 项适合选定前做最后一道核查。

## 技能到位后怎么用

技能落在 `skill/<技能名>/`，三个部分：

| 部分 | 是什么 |
|---|---|
| `SKILL.md` | 上游原文，一个字节都不改 |
| `来源与许可.md` | 谁写的、哪个版本、从哪儿下的、什么许可证 |
| `本地化补丁.md` | 本项目补的层：行为约定、边界、装载与验证（**怎么装、怎么验都看这里**） |

装到本机 Agent 后，用自然语言描述问题就会自动触发，不需要说技能名。每个包的 `本地化补丁.md` 末尾都有一句话验证法，装载后照那个试一遍。

## 边界（用之前先看这段）

- **不做诊断、不开药。** 不说「就是 XX 病」，不给药品名和剂量。
- **危机优先。** 出现自伤、自杀念头、虐待、家暴、霸凌致伤，立刻停，转 12355 青少年服务台、12356 全国心理援助热线、儿童心理科、110。
- **不做对错裁判。** 隔代养育、夫妻分歧这类，只给能商量的一致口径，不站队。
- **不承诺疗效。** 不说「几天见效」。
- **孩子和家庭的对话内容不上网、不入库。** 本地留存要事先说清楚，并且可以选不留。

## 怎么卸载

删掉 `skill/<技能名>/` 目录，再从本机 Agent 的 skills 目录里删掉同名文件夹即可。没有后台常驻进程，没有数据残留（除非你自己开了本地留存）。
