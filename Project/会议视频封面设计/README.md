# 会议视频封面设计 · 这是什么

每开一届会，配一张 16:9 横版封面，用在会议集锦视频上。

## 产出什么

3840×2160 PNG。两行金色立体字，上行「全惠惠第X届」，下行「精英培训会集锦」，底子是天空、会场或城市。需要冲劲时给第三层标语。

## 文件在哪

仓库里只有规范，图和风格库都在工作目录：

```
E:\260930_全惠惠工作合集\261012_平面设计合集\261029_会议视频封面设计
├── 风格库\    十套封面风格，索引与轮转记录在 索引.md
├── 底图\      每届的无字底图，按届分文件夹
└── 成品\      每届成品，按届分文件夹
```

## 怎么开工

1. 读 `openspec/specs/会议封面/spec.md`，规矩都在那儿
2. 读工作目录的 `风格库\索引.md`，按轮转规则挑一套，再读那套的 `风格卡.md`
3. 照 `openspec/changes/` 里在跑的改动做

## 两段式

先出无字底图，存档；再叠文字。底图独立，换底图不用重排字，改字不用重出底图。

## 别和别的项目混

朋友圈早图晚图归 `Project/全惠惠平面设计`，那套风格库和这套不通用。视频成片归 `Project/全惠惠视频制作`。
