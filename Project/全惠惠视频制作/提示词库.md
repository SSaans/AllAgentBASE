## 一、S / C / T 三段

### 1.1 为什么分三段

缓存只认一件事：这次请求的开头跟上次是不是一模一样。

所以把提示词切成三块，顺序固定：

```
S 段  系统包（永远不变，原样复制）
C 段  公司常量（理念、口号、颜色）
T 段  这次的任务（只有这里动）
```

新东西一律加在最后。今天的日期塞到最前面，后面全部白算。

### 1.2 三条使用规矩

1. S 段整段贴。不润色，不改标点，不调顺序
2. 一批活连着做，隔太久缓存就过期
3. 要改 S 段或 C 段，攒到这批交完再改

### 1.3 S1 段：给 GPT 当 agent 用

> 原样复制，后面接 C 段和 T 段。

```
你是全惠惠公司的视频制作执行。你负责把片子做出来：写文案、排镜头、写每一段的提示词，交给视频模型生成，再从生成的片子里挑出能用的。

注意：你不能自己生成视频。写好的提示词交给视频模型去跑，你负责判断出来的是不是对的。

公司做四块业务：直销、开会讲课、房产、购物平台。看片子的人四十岁以上为主，董事长七十多岁。

规矩：
1 画面稳、正、有分量，像大公司出品。不做网红风，不做卡通，不玩梗
2 画面里的字尽量少。要出现就一行说一件事，字号大。logo 用参考图或者简单带过，别硬画细节
3 一条片子只讲一件事
4 不用没授权的音乐、影像、人物

输出顺序：
先给镜头表（镜头号、时长、画面、镜头怎么动、屏上文字），再给每段的生成提示词。
提示词写清：画面内容、光线、颜色、镜头怎么动。别写形容词堆砌，别写「很有气势」这种没法执行的话。
各镜头时长加起来要等于要求的总时长。
```

### 1.4 S2 段：给只吃提示词的模型

> 原样复制，接在画面描述前面。

```
画面风格：中国企业宣传片，端庄大气，深色背景配金色光效，电影级布光，浅景深，画面干净，居中构图，中间留一块安静的区域。
画质：4K 质感，细腻颗粒，无噪点。
禁止出现：文字、字母、标志、水印、卡通人物、云纹云朵、荧光色、故障风、快闪、可辨识的地标建筑。
镜头：稳定运动，缓慢推近或平移，不晃动。
```

### 1.5 C 段：公司常量

```
【品牌】全惠惠 QUANHUIHUI
【核心理念】全心全意聚商机，互惠互利赢未来
【使命】全心全意打造新商业聚合赋能系统，共创共建共享共赢
【愿景】为消费者省钱、为商家引流、为事业伙伴创造价值
【主色】中国红，参考 #C8102E 到 #D02B25
【辅色】深黑 #111111、暖金 #C9A227、纯白 #FFFFFF
【禁色】荧光色、糖果色、彩虹渐变
```

色值是从 logo 上取的参考区间，要精确值就自己从原稿采样。

### 1.6 T 段：这次的任务

```
【这次的任务】
类型：T03 logo 片尾
时长：11 秒
用途：会议大屏片尾，也会嵌在宣传片后面
必须出现：凤凰图形、书法体「全惠惠」、英文 QUANHUIHUI、理念八个字
不能出现：AI 写歪的字、变形的标志、云纹、花哨光斑、卡通元素
镜头数：4
```

## 二、T03 · logo 片尾

### 2.0 开工前先看几条

找三个大品牌的 logo 动画看两遍。注意它们怎么起手、定格停多久、光从哪来、结尾怎么收。看完再写提示词，比凭空想快得多。

这个类型十一秒左右，分四段：2.5 + 3 + 3 + 2.5。

### 2.1 logo 怎么交给模型

两条路，先试第一条：

1. **给参考图。** 把 logo 图喂进去，让它在这个基础上动。形状能保住，颜色也会跟着走
2. **只给描述。** 没法给图时，就描述它长什么样：红金凤凰图形，下方书法体「全惠惠」，再下面一行英文

预期要放平：动态里一闪而过的画面，模型画得不那么准也看不出来。要做静止定格的大落版，宁可画面简单点，别让模型硬抠字。

logo 图片在 `H:\Program\全惠惠平面设计\assets\logo-original-render.png`，1507×506，透明底。

### 2.2 方案 A · 黑金，光起

气质肃、亮、有分量。会议片尾、正式场合用它。

| 段 | 时长 | 画面 | 镜头怎么动 | 屏上字 |
|---|---|---|---|---|
| s01 | 2.5s | 纯黑，中间一点金光 | 静止，光点呼吸 | 无 |
| s02 | 3.0s | 光点散成光束向四周铺开 | 慢慢后拉 | 无 |
| s03 | 3.0s | 黑底，金色粒子细密飘落，中间留空 | 几乎不动 | logo |
| s04 | 2.5s | 黑底渐深，粒子下沉 | 静止 | 理念八个字 |

**s01**

```
纯黑背景正中间一个很小的金色光点，缓慢明灭，四周全黑，没有别的东西，极简。
```

**s02**

```
黑底，中间的金色光点向四周散成柔和光束，粒子跟着光一起散开，画面保持深色，没有文字。
```

**s03**

```
深黑背景，很细的金色粒子从上往下慢慢飘，中间一大片是空的，左右有淡淡的金色光晕，浅景深。
```

**s04**

```
深黑背景，金色粒子缓缓下沉，光从上往下渐暗，中间留空，画面收得很稳，没有文字。
```

### 2.3 方案 B · 红绸揭幕

喜庆、隆重。表彰会、年会、招商会用。

| 段 | 时长 | 画面 | 镜头怎么动 |
|---|---|---|---|
| s01 | 2.5s | 深红绸面铺满画面，有褶皱和柔光 | 极慢推近 |
| s02 | 3.0s | 绸幕从中间向两侧分开，露出黑底 | 静止，幕退开 |
| s03 | 3.0s | 黑底，四周金色轮廓光，中间空 | 极慢推近 |
| s04 | 2.5s | 黑底渐暗，金光收拢熄灭 | 静止 |

**s01**

```
深红色绸缎特写铺满画面，褶皱自然，表面有流动的柔光，中国红，庄重，没有文字。
```

**s02**

```
深红绸幕从正中间向左右缓缓分开，露出后面的深黑背景，绸边有金线，动作平稳，没有文字。
```

**s03**

```
深黑背景，画面四周一圈柔和的金色轮廓光，中间大片深色留空，极简，电影质感。
```

**s04**

```
深黑背景，金色余光从四周往中间收，慢慢灭掉，画面沉进纯黑。
```

### 2.4 方案 C · 空间推近

现代、有空间感。宣传片片尾、招商视频用。

| 段 | 时长 | 画面 | 镜头怎么动 |
|---|---|---|---|
| s01 | 2.5s | 深色空间，一道光柱斜切进来 | 缓慢平移 |
| s02 | 3.0s | 光柱扫过，浮起细尘 | 跟着光柱平移 |
| s03 | 3.0s | 深色空间，中间留白，边缘有光 | 极慢推近 |
| s04 | 2.5s | 光暗下去 | 静止 |

**s01**

```
深色空旷空间，一道柔和的暖白光柱从左上斜切下来，空气里没有杂物，极简，电影质感。
```

**s02**

```
光柱缓慢横移扫过深色空间，光束里浮着细小尘埃，明暗对比强，画面很稳。
```

**s03**

```
深色空间，中间一大片空的，四周有很淡的暖色环境光，浅景深，镜头慢慢往前推。
```

**s04**

```
空间里的光从上往下一点点灭掉，画面沉入深黑。
```

### 2.5 顺序

```
① 三个关键帧先定下来：开头、中间、结尾。看一眼对不对
② 四段分别生成，每段给首帧和尾帧，配一句运动描述
③ 四段在生成工具里拼成整条
④ 配乐。情绪跟着 s02 起来，s04 收住
⑤ 屏上的字最后处理，两行以内
```

### 2.6 排版位置

- logo 中心放在画面百分之四十二的高度
- 理念八个字在 logo 下面，间距大约 logo 高度的四成
- 四周留白不小于 120 像素，大屏会裁边
- 字不压 logo，不压人

## 三、T05 · 企业宣传片

### 3.1 六十秒怎么分

| 段 | 时长 | 讲什么 |
|---|---|---|
| 开头 | 5s | 一句狠话，或者一个大场面 |
| 我们做什么 | 15s | 三件事：消费者省钱、商家引流、伙伴赚钱 |
| 凭什么 | 15s | 聚合、赋能、产业覆盖 |
| 谁受益 | 15s | 三方各一句 |
| 收尾 | 10s | 理念八个字，加品牌 |

### 3.2 旁白配比

六十秒里旁白写到一百二十字上下就够。画面能说清的，嘴就别再讲一遍。

## 四、关键帧怎么用

### 4.1 步骤

```
① 先出这一段的头一张和尾一张
② 两张图加一句运动描述，交给视频模型
③ 模型只负责中间怎么动
```

### 4.2 运动描述写四样

镜头怎么动、光怎么变、什么东西在动、多快。

| 别写 | 写成 |
|---|---|
| 有气势一点 | 镜头从远到近推三成，鼓点落在第二秒 |
| 高级一点 | 背景压暗三成，金色光晕只留右边 |
| 动态感强 | 粒子从下往上飘，速度均匀，全程不停 |

什么情况不用关键帧：单镜头、纯光效、没有主体。直接一句提示词就行，多一次出图反而亏。

## 五、负面词

每次生成都带上：

```
文字, 字幕, 字母, 汉字, logo, 标志, 水印, 签名,
卡通, 动漫, 手绘, 涂鸦, 表情包,
云, 云纹, 云朵, 祥云, 烟雾,
荧光色, 糖果色, 彩虹渐变, 高饱和,
故障风, 快闪, 抖动, 晃动,
可辨识的地标建筑,
低分辨率, 噪点, 模糊, 变形, 畸变
```

「云」是用户明确不要的，云纹、云海、云雾都算。

## 六、把话翻成画面的例子

领导的原话通常没法直接用。翻的时候抓住材质、光、颜色、镜头、动作这五样，至少说清三样。

| 原话 | 翻成 |
|---|---|
| 大气 | 画面留白多，主体占三分之一，镜头慢慢推 |
| 高级 | 暗背景，一束侧光，表面有反光 |
| 有科技感 | 深蓝底，细光线网，光点流动 |
| 五彩斑斓的黑 | 黑底铺一层镭射膜，光一斜就散出彩色 |
| 热闹 | 人多，动作快，鼓点密 |
| 有未来感 | 冷白光，镜面地板，线条向远处收 |
| 厚重 | 慢，画面沉，色温偏暖，金属质感 |

翻完念一遍。自己脑子里能不能看见那个画面。看不见，说明还没翻到位。
