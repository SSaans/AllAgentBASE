## 一、S / C / T 三段结构：让缓存命中

### 1.1 为什么这么排

缓存只看一件事：**这次请求的开头跟上次是不是逐字节一样**。

所以把请求切成三段，固定顺序，永不调换：

```
S 段  系统包     ← 永远不变，逐字节复制
C 段  公司常量   ← 只随版本升级变，平时不动
T 段  本次任务   ← 只有这里动
```

**动的东西只能放最后。** 你把今天的日期塞进开头，后面全部缓存作废。

### 1.2 三条使用纪律

1. **S 段整段贴，一个字不改。** 不许润色、不许改标点、不许调段落顺序
2. **一批活连着做。** 缓存有存活时间，中间隔太久就白攒
3. **发现要改 S 段或 C 段，攒到这批交完再改**，改完在 `CHANGELOG.md` 记一行

## 五、首尾帧锚定法（省钱的核心手艺）

### 5.1 怎么用

```
① 用图像生成或裁帧，做出这一镜的「第一帧」和「最后一帧」
② 把两张图 + 一句运动描述交给视频模型
③ 模型只负责中间怎么动
```

### 5.2 运动描述怎么写

只写四样：**镜头怎么动 / 光怎么变 / 什么在动 / 多快**。

| 别写 | 写成 |
|---|---|
| 让它很有气势 | 镜头从远到近推 30%，鼓点落在第 2 秒 |
| 高级一点 | 背景压暗三成，金色光晕只留右侧 |
| 动态感强 | 粒子从下往上飘，速度均匀，全程不停 |

### 5.3 什么时候不用

- 单镜头、纯光效、没有主体 —— 直接一句提示词就够，锚帧反而多花一次图
- 需要复杂运镜（环绕、穿墙）—— 锚帧会限制模型，效果更差

## 七、本地合成命令条

> ffmpeg：`C:\Users\Unbox\AppData\Roaming\LottieViewConvert\ffmpeg\ffmpeg.exe`
> 本机**没有 ffprobe**。查参数：`ffmpeg -i 片.mp4 -f null -`，读 stderr。

### 7.1 查规格

```bash
ffmpeg -i in.mp4 -f null -
```

### 7.2 拼接（同规格，不重编码）

写 `list.txt`：

```
file 's01.mp4'
file 's02.mp4'
file 's03.mp4'
file 's04.mp4'
```

```bash
ffmpeg -f concat -safe 0 -i list.txt -c copy base.mp4
```

### 7.3 叠 logo（带淡入淡出）

```bash
ffmpeg -i base.mp4 -loop 1 -t 11 -i logo.png -filter_complex \
"[1:v]scale=980:-1,format=rgba,fade=in:st=5.5:d=0.8:alpha=1,fade=out:st=10.2:d=0.8:alpha=1[lg];[0:v][lg]overlay=(W-w)/2:(H-h)*0.42" \
-c:a copy -c:v libx264 -pix_fmt yuv420p out.mp4
```

`(H-h)*0.42` 让 logo 中心落在画面 42% 高度。

### 7.4 上字幕（用 ASS，中文最稳）

写 `sub.ass`（UTF-8）：

```
[Script Info]
ScriptType: v4.00+
PlayResX: 1920
PlayResY: 1080

[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, OutlineColour, BackColour, Bold, Alignment, MarginL, MarginR, MarginV
Style: Main,Noto Serif SC,72,&H00FFFFFF,&H00000000,&H00000000,1,2,60,60,150

[Events]
Format: Layer, Start, End, Style, Text
Dialogue: 0,0:00:08.50,0:00:11.00,Main,全心全意聚商机　互惠互利赢未来
```

```bash
ffmpeg -i in.mp4 -vf "ass=sub.ass" -c:a copy out.mp4
```

> 字体名要跟系统里装的一致。Noto Serif SC 若不识别，先双击 `NotoSerifSC-Bold.otf` 装进系统，或用 `simhei`。

### 7.5 混音（人声清楚、音乐垫底）

```bash
ffmpeg -i video.mp4 -i music.mp3 -filter_complex \
"[0:a]volume=-6dB[a0];[1:a]volume=-18dB,atrim=0:11[a1];[a0][a1]amix=inputs=2:duration=first" \
-c:v copy -c:a aac -ar 48000 -ac 2 out.mp4
```

只有音乐没有人声时，音乐拉回 `-12dB` 左右。

### 7.6 压片（交付规格）

```bash
ffmpeg -i in.mp4 -c:v libx264 -profile:v main -pix_fmt yuv420p -r 25 -b:v 12M \
-c:a aac -ar 48000 -ac 2 -movflags +faststart out.mp4
```

### 7.7 导封面

```bash
ffmpeg -ss 6 -i in.mp4 -frames:v 1 -q:v 2 cover.jpg
```

### 7.8 竖版（朋友圈/视频号）

```bash
ffmpeg -i in.mp4 -vf "scale=-2:1920,crop=1080:1920" -c:a copy out-vertical.mp4
```
