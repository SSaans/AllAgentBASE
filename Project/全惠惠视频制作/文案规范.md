## 一、视频文案跟朋友圈文案不是一回事

| | 朋友圈文案 | 视频文案 |
|---|---|---|
| 给谁读 | 一个人拿着手机看 | 一群人看大屏，或者划过手机 |
| 时间 | 想读多久读多久 | 一句字幕停留 2–3 秒 |
| 写法 | 五段式，150–200 字 | 短句，一屏一句，读完就走 |
| 失败长什么样 | 平淡、没人转发 | 字太多、念不完、看完不记得说了啥 |

一条片子能让人记住的，通常不超过三句话。**所以先定那三句，剩下的都是给这三句垫场的。**

## 二、底料：公司经营理念

> 以下摘自 `设计资料\全惠惠经营理念框架文件(1).docx`。**原句照录，不改字**。新口号以原件为准。

### 2.1 核心六句

| 项 | 原文 |
|---|---|
| 核心理念 | 全心全意聚商机　互惠互利赢未来 |
| 愿景 | 为消费者省钱、为商家引流、为事业伙伴创造价值 |
| 使命 | 全心全意打造新商业聚合赋能系统，共创共建共享共赢 |
| 价值观 | 利他共生，消费有道，聚合赋能，诚信经营，持续增长 |
| 品牌释义 | 「全」即全心全意；「惠」与消费者、商家、事业伙伴互惠互利；叠音强调普惠初心与互惠共赢的加倍效应 |
| 一句话定位 | 全惠惠不只是一个平台，更是一种新商业的践行者 |

### 2.2 三大服务主体（写「给谁」的时候用）

| 主体 | 理念里的定位 | 给什么 |
|---|---|---|
| 消费者 | 商业的源头 | 给价值：省钱、省心、消费有道 |
| 实体商家 | 经济的脊梁 | 给增量：引流、会员共享、异业互推、数字化工具 |
| 事业伙伴 | 生态协同方 | 给成长收益：培训、运营支持、分润、晋升 |

### 2.3 5W1H 六问（写「讲什么」的时候用）

| 问 | 答案要点 |
|---|---|
| Who 为谁做 | 消费者、实体商家、事业伙伴，三方协同 |
| What 做什么 | 以消费场景为纽带，以资源聚合为桥梁，以数字化赋能为核心，搭建多方共建共赢的数字化服务平台 |
| Why 为什么做 | 优化传统商业链路，打通交易链路，多方共赢 |
| When 何时做 | 三重机遇交汇：消费主权觉醒、实体商业数字化转型、共同富裕政策导向 |
| Where 在哪做 | 线上电商入口、线下实体门店、社群信任、全产业覆盖 |
| How 如何做 | 商家赋能机制、消费权益机制、多业态协同机制 |

### 2.4 写作时怎么用这套底料

**不要搬原句上屏。** 原句是给读的，不是给看的。

| 原句 | 上屏改成 |
|---|---|
| 全心全意打造新商业聚合赋能系统，共创共建共享共赢 | 一起干，一起赚 |
| 为消费者省钱、为商家引流、为事业伙伴创造价值 | 你省钱，他引流，我赚钱 |
| 依托数字化工具优化传统商业链路 | 让生意好做一点 |
| 打通供需链路，推动产业链各方协同发展 | 把买家卖家拉到一张桌子上 |

改的是**说法**，不是**意思**。意思跑偏就是造假。

## 三、口号库：不会写就照抄

**硬要求**：屏上大字和旁白首句，必须能在下面找到出处，或者按 §3.2 的五法变出来。**不许自己编标语。**

### 3.1 公司现用口号（13 条）

横幅 8 条：

1. 全心全意聚商机，互惠互利赢未来
2. 奋战一百天，冲刺一个亿
3. 奋战百日不停，业绩再攀高峰
4. 聚力同心作战，百日共铸辉煌
5. 抢抓百日机遇，聚力赢战市场
6. 凝心聚商机，实干创佳绩
7. 全心抢抓商机，百日互惠共赢
8. 团结齐拼搏，携手共辉煌

小红旗 5 条：

9. 全力以赴，完成任务
10. 团结聚力，和谐共赢
11. 共建共创，共拓商机
12. 友好协作，互惠共赢
13. 和谐共进，赢取未来

> 摘自 `设计资料\全惠惠横幅及小红旗内容.docx`。用户往原件里加了新口号，**以原件为准**，这里只是摘抄。

### 3.2 洗稿五法（在原句基础上变，不许凭空造）

| 法 | 做法 | 例 |
|---|---|---|
| 换对象 | 把「谁」换掉 | 团结齐拼搏 → 中山齐拼搏 |
| 缩句 | 砍到四字或六字 | 奋战一百天，冲刺一个亿 → 百日冲刺 |
| 换动词 | 动词换更硬的 | 抢抓机遇 → 咬住机遇 |
| 加落点 | 后半句落到具体动作 | 全力以赴，完成任务 → 全力以赴，把事做成 |
| 对仗化 | 改成前后对得上 | 共建共创，共拓商机 → 共建共创，共享共赢 |

**五法不许叠加超过两层。** 变三次以上，原句的意思就散了，那不叫洗稿，叫另写。

### 3.3 分类（写之前先定这条属于哪一类）

攻坚 / 团结 / 共赢 / 机遇 / 实干 / 决心。

定完类，语气就定了：攻坚要硬，团结要暖，共赢要敞亮，机遇要急，实干要沉，决心要狠。

## 四、三种形态怎么写

### 4.1 屏上大字

**字数**：≤12 字/行，≤2 行。
**判据**：站在三米外能一眼读完。

写法：

- 主句用口号库原句，两行断开
- 不用标点（书名号、引号都不要）
- 一行一个意思，不硬断词

例：

```
奋战一百天
冲刺一个亿
```

### 4.2 旁白

**字数**：每句 ≤15 字，全片 ≤120 字。
**判据**：念出来不打结，换气点在一句话结束处。

写法：

- 动词开头。「我们做三件事」比「我们的业务包含三个方面」强
- 一句一个信息，不嵌套
- 不用书面连接词：此外、从而、进而、基于此
- 不用英文缩写：B端、C端、SOP、GMV

例（60 秒宣传片，约 110 字）：

```
我们做一件事。
让消费者花得少一点。
让商家客人多一点。
让愿意干的人，赚得到钱。
这三件事，我们做了很多年。
全惠惠。
```

### 4.3 落版

**固定句式，不许改：**

> 全惠惠，全心全意聚商机，互惠互利赢未来。

片尾缩短版可用：

> 全心全意聚商机　互惠互利赢未来

落版必须跟 logo 同框，logo 在上或左，字在下或右。

## 五、常见错误对照

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| 把理念整段念一遍 | 念不完，记不住 | 只留八个字 |
| 「依托数字化工具优化商业链路」 | 念出来没人懂 | 「让生意好做一点」 |
| 一屏塞四行字 | 三秒读不完 | 砍到两行 |
| 「赋能生态闭环」 | 行业黑话 | 「大家一起赚钱」 |
| 「我们致力于……」 | 汇报腔 | 直接说事 |
| 通篇形容词 | 没有画面 | 换成动作和数字 |
| 编客户案例 | 一问就露馅 | 只讲机制，不讲战绩 |
| 喊「第一」「唯一」 | 违反广告法 | 改成具体事实 |

## 六、合规词表（定稿前机器扫一遍）

### 6.1 禁词（出现即拦）

```
稳赚　保本　零风险　一定能赚　躺赚　暴利　包赚
最好　最大　最强　第一　唯一　顶级　国家级　世界级
保证收益　投资回报　必涨　翻倍　升值　增值空间
包治　根治　疗效　治愈　神奇　特效
提现　变现　转让（涉及消费权益时）
```

### 6.2 慎用词（要改口径）

| 词 | 改法 |
|---|---|
| 会员分红 | 推广服务佣金 |
| 拉人 | 介绍、分享 |
| 投资 | 合作、参与 |
| 收益 | 佣金、回报（须限定为推广服务所得） |
| 免费领 | 消费后可兑换权益 |

### 6.3 消费权益口径（一个字都不能改）

> 权益仅限本人后续消费抵扣使用，**不可提现、不可变现、不可转让**。

涉及权益的文案，必须完整带上这三点，不许简写成「可提现」或「能变现」。

### 6.4 房产与直销

- 房产：不承诺升值，不做投资回报表述，不说「必涨」「翻倍」
- 直销：不描述「拉人头获利」，只讲「按本人直接有效成交订单获取推广服务佣金」

## 七、交付格式

文案跟片子放一起，文件名 `<月日>-<类型短名>-文案-v<N>.md`：

```markdown
# 片尾 logo · 文案 v1

## 屏上大字
（第一行）
（第二行）

## 旁白
（每行一句，标注时长）

## 落版
全惠惠，全心全意聚商机，互惠互利赢未来。

## 出处
- 主标语：横幅第 1 条
- 旁白：洗稿五法·缩句
- 合规：已扫，无命中

## 字数
屏上 8 字 / 旁白 0 字 / 合计 8 字
```

**出处必须写。** 说不清出处的句子，删掉重写。
