# 规格变更：本机访问控制

## Purpose

规定面板与接口的可见范围，确保这套自用设施不会被公网访问，也不把凭据写进仓库。

## ADDED Requirements

### Requirement: 只对本机开放

系统 SHALL 只监听本机地址，不接受来自外网的连接。

#### Scenario: 从外网访问

- **WHEN** 从另一台机器访问面板地址
- **THEN** 连接被拒绝，面板不可见

#### Scenario: 本机访问

- **WHEN** 在本机打开面板地址
- **THEN** 正常进入，无需额外放行

### Requirement: 凭据不入库

系统 SHALL 让密钥、账号只存在本机配置或凭据管理器中，仓库内任何文件都不含明文凭据。

#### Scenario: 提交配置

- **WHEN** 提交与该项目相关的文件
- **THEN** 暂存内容里不含任何密钥明文，示例配置只用占位符
