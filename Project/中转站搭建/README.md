# 中转站搭建 · 这是什么

一句话：**在自己电脑上装一个面板，把手上那几家中转站的 key 都接进去，以后换站不用改客户端。**

---

## 一、它解决什么问题

现在调 AI，是直接在某一家站开 key、填进客户端。麻烦在于：

- 换一家站，电脑上每台客户端里的地址和 key 都得改一遍
- 某家站挂了、涨价了、跑路了，只能干等或手动切
- 钱花在哪、用了多少，各家分散，看不清
- 攒了几家的 key，也没法让它们互相兜底

做完这个项目之后：

- 客户端只配**一个地址、一个 key**，再也不动
- **几家的 key 同时挂着**，一家挂了自动用下一家
- 面板里能看见谁在用、用了多少
- 以后加新站，只在面板里点几下

---

## 二、怎么做

用开源项目 [new-api](https://github.com/Calcium-Ion/new-api)。它本身就是干这个的——把所有上游接口收成一个口子，统一发出去。

你电脑上只要能跑 Docker 就能装；**不想装 Docker 也行**，它有现成的 Windows 程序，解压双击就跑，什么都不用配。

> 顺便说一句：你那份调研报告里 22 家站用的都是另一个面板（sub2api）。那个是给「手里有一堆 AI 订阅账号、想拆开分给多人用」的场景准备的。你没有订阅账号，上游全是别家的 key，所以要用 new-api —— 渠道管理正是它的看家本事。

---

## 三、做完之后能干什么

| 能 | 说明 |
|---|---|
| 一个口子调所有模型 | 客户端地址固定 `http://127.0.0.1:3000/v1` |
| 多家上游轮流兜底 | 一家挂了自动换下一家 |
| 看用量和日志 | 哪家用了多少、什么时候用的，一目了然 |
| 换站不动客户端 | 新站只在面板里加一个渠道 |
| 接 Claude Code | 面板能做格式转换，哪怕是只支持标准接口的站也能接 |

---

## 四、不会做什么（先说清楚）

- **不对外、不收钱、不开公网**。这个是自用工具，地址只在自己电脑上能访问
- **不碰订阅账号、不做号池**。手上没有那类账号，而且风险高
- **不装到服务器上**。本机先跑通，将来要 7×24 再单独说
- **不改别人的代码**。只部署、只配置

---

## 五、用之前要知道

- **自己电脑不能关机**。关机就没服务了，这是本机方案的天然限制
- **上游站的 key 得自己拿着**。这个项目不提供任何 key，也不推荐任何一家站
- **报告里那 22 家仅供参考**。报告自己都写了「不构成任何推荐」，而且里面很多是逆向渠道，便宜但随时可能失效。价格数据也是 9 月 19 号的，早就变了，下单前自己看站内实时价格
- **别把站点地址和 key 发给别人**，也别提交到仓库里
