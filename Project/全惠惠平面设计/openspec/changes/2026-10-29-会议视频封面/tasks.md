# 任务

两段走：先底图，后文字。每步自己验过再往下。参数取 `design.md`。

## 1. 定届号、挑风格

- [ ] 1.1 查 `风格库\索引.md`，筛可用、按上次使用升序取前 5，挑一个不与上一届同号的
- [ ] 1.2 记下编号、字区、字高、对齐方式
- [ ] 1.3 打开那套的 `风格卡.md`，底图按它的提示词出

## 2. 出底图

- [ ] 2.1 按提示词出 16:9 底图，无字、无数字、无 logo
- [ ] 2.2 逐张检查：乱码字、假界面、外地地标、清晰人脸、脏天空，有一条就重出，最多三次
- [ ] 2.3 存 `底图\第N届\CFxx-底图.png` 与 1280×720 预览图

## 3. 渲染字层

- [ ] 3.1 按 `design.md` 第三节的硬线排两行，字位、占宽、错落自己定
- [ ] 3.2 单独裁一行自查：字接近正方，竖画横画粗细差得不远，没有拉压变形
- [ ] 3.3 金色四件事齐（挤出、渐变、白描边、投影），按判据验厚度
- [ ] 3.4 与 24 届 `fm24_1.1.1.png` 并排看，气势和金色深浅对得上

## 4. 出片

- [ ] 4.1 出 3840×2160 PNG，sRGB，≤ 8 MiB
- [ ] 4.2 缩到 640×360，两行标题读得出来
- [ ] 4.3 放大 100% 看字的左下角，有厚度和白边

## 5. 标语版（可选）

- [ ] 5.1 第三层标语字高 110，居中压下部，白字金描边
- [ ] 5.2 标语只从横幅库第 2–8 条取，不许自编

## 6. 交付与回填

- [ ] 6.1 改名入 `成品\第N届\`，改稿加 v2、v3，不覆盖已交版
- [ ] 6.2 校验尺寸、色彩、体积、届号、与上届不同号
- [ ] 6.3 索引里回填本届编号、日期、累计
