# 设计

## 一、出图分两段

**先底图，后文字。** 两段分开存、分开换，底图不满意只重出底图，字不用重排。

```
第一段  选风格 → 按风格卡提示词出 16:9 无字底图 → 自检 → 存 底图\第N届\CFxx-底图.png
第二段  渲染层叠金色立体字（两行 + 可选标语） → 存 成品\第N届\第N届_封面_CFxx_v1.png
```

底图**不带任何文字、数字、logo**。模型画出可辨认的字，一律弃用重出。

## 二、每届换风格

风格库十套，在 `风格库\`，一览表在 `风格库\索引.md`。

轮转：筛可用 → 按上次使用升序 → 取前 5 → 挑一个 → **不得与上一届同号** → 回填。

24–27 届全是 CF01，从第 29 届起轮转，前面用过的往后排。十套够用一百届不撞。加新风格编 CF11 起，只增不回收，判断标准是换了一种视觉语言，只换颜色或换张照片的不算。

## 三、版式

两张验收成品是**参照**，不是坐标表。骨架就这几件事：画布 3840×2160；两行字，上行「全惠惠第X届」，下行「精英培训会集锦」；整体压在画面中上，底部留给城市或舞台；上行比下行略大。

**硬线，破了就是错：**

- 不顶边。左右、上下都留出余量，字不能贴到画布边缘。
- 两行不许贴在一起，字与字不许粘成一条。
- 字形不许拉压变形。判据：单独裁一行出来看，每个字接近正方，竖画和横画粗细差得不远。
- 缩到 640×360，两行还读得出来。
- 上行不小于下行。

**下面这些随便定，别求届届统一：** 居中还是错落、占画宽多少、压在哪、要不要年份数字、字距松紧、行间多少。同一届里两行得是一个调子。

字宽估不准就抓一个感觉：一行 8 个字，撑到画宽的七到九成之间，两头留白对得上。

十套风格只规定字区落在哪一带，具体位置出图的人对着底图定：

| 编号 | 字区 |
|---|---|
| CF01 | 中部，可压年份 |
| CF02 | 舞台上方暗区 |
| CF03 | 上三分之一天空带 |
| CF04 | 上部暗区 |
| CF05 | 太阳上方净空 |
| CF06 | 夜空上半 |
| CF07 | 幕布中部 |
| CF08 | 中央暗区 |
| CF09 | 上部天空 |
| CF10 | 通版 |

字体用粗黑体，不许宋体、楷体、细体。

## 四、金色

四件事要有：挤出厚度、字面金色渐变、白描边、投影。再加一层顶面高光更好。

- 金色要亮，别收成锈色。红底上尤其明显。
- 亮底加重投影，不然字浮起来。

色值只作参考：渐变 #FFF3C9 → #FAC756 → #CE8F24，挤出 #6B3E0A，投影 #331F06。可以自己调，调完按判据验。

判据：放大 100% 看字的左下角，能看出厚度和白边。看不出就是扁的。

## 五、第三层标语（可选）

比正文小一档，居中压在字区下方，白字加金描边。内容只能取横幅库第 2–8 条（奋战、聚力、抢机遇那几条），不许自编。品牌口号「消费全惠惠，笔笔都实惠」不上封面。

## 六、届号

阿拉伯数字转中文，1–99 覆盖。10 → 第十，19 → 第十九，20 → 第二十，29 → 第二十九届。写错就是错版。

## 八、底图从哪来

1. 首选按风格卡提示词出图（16:9，无字）。
2. CF01 可直接用原模板 `bg.mp4` 抽帧：`E:\260930_全惠惠工作合集\260930_会议视频合集\001-原初模板\001-会议片头模板\01-清新云层\...\(素材)\视频\bg.mp4`，1920×1080，取 t=5s（t=0 是白屏），2 倍 Lanczos 放大到 3840。
3. CF03、CF09 可用当届 `DJI_*.MP4` 抽的城市或会场帧。

原素材只读，不移动、不改名、不删除。
