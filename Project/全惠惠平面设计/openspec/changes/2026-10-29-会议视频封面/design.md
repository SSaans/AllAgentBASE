**先底图，后文字。** 两段分开存、分开换，底图不满意只重出底图，字不用重排。

```
第一段  选风格 → 按风格卡提示词出 16:9 无字底图 → 自检 → 存 底图\第N届\CFxx-底图.png
第二段  渲染层叠金色立体字（两行 + 可选标语） → 存 成品\第N届\第N届_封面_CFxx_v1.png
```

底图**不带任何文字、数字、logo**。模型画出可辨认的字，一律弃用重出。

## 三、版式参数

CF01 是已验证的基线，实测值如下（3840 宽）。其他风格换的是**字区位置**，字号、行距、金色工艺照这套走。

| 项 | 基线值 | 说明 |
|---|---|---|
| 画布 | 3840 × 2160 | 16:9，PNG，sRGB |
| 上行「全惠惠第X届」 | 字高 518，左起 x=140，字顶 y=516 | 宽约 3280，占满 85% |
| 下行「精英培训会集锦」 | 字高 504，右端 x=3674，字顶 y=1099 | 右移错落，不居中 |
| 行间净空 | 65 | 上行底 1034 → 下行顶 1099 |
| 年份大字 | 白 92%，压在标题后 | 程序画，可关 |
| 天空 | 左上 #EAF3FF → 左中 #C3D9F7 → 右上白 | CF01 专用 |

改动许可：

- 字位按风格卡写的「字区」放，不硬套 y=516。
- **字高区间 420–520**，再小缩略图读不出，再大一行 8 字放不下。
- 上行可居中、可左起，下行错落量 0–200 之间调。
- 上下边缘至少留 60 px，左右至少留 140 px。

### 🔴 字号、字高、行宽怎么换算

这一节是 2026-10-29 出事故后补的。当时执行方把整行文字渲染成一张图，再**非等比缩放到指定的宽和高**，字被横向压成瘦高条，竖画细得像针，横画没变，四不像。

硬规矩：

| 项 | 值 |
|---|---|
| 字号 S | 直接等于你要的视觉尺寸，**不许事后缩放高度** |
| 字高 | ≈ 0.96 × S |
| 一行 8 字自然宽 | ≈ 8 × S |
| 行宽预算 | 3300–3500，左右各留 ≥150 |
| 允许的横向压缩比 | 0.85–1.00，两行必须用**同一个**比例 |
| 低于 0.82 的压缩 | 禁止，竖画会细到失衡 |
| 字距 | 字号 × 2%–3%，**不许为 0** |
| 行间 | 70–80，按上行实际字高往下推，不按固定 y |

举例，字高 500 那行：S≈520，自然宽 4160，超预算 → 横向压到 0.85 得 3536，仍超 → 再把字距收到 2% 或压缩到 0.82。**宁可字小一点，不许把字压变形。**

判据：把这一行单独裁出来看，每个字是不是接近正方形、竖画和横画粗细差得不远。差太多就是压过头了。


字体用粗黑体（Noto Sans SC 900 近似），不许宋体、楷体、细体。

## 四、金色立体字

四层，缺一层就扁：

| 层 | 参数 |
|---|---|
| 挤出厚度 | 深棕 #6B3E0A，斜右下偏 14–16 px，分 16 层叠 |
| 字面渐变 | 上 #FFF3C9 → 中 #FAC756 → 下 #CE8F24 |
| 描边 | 白 #FFFDF6，9 px |
| 顶面高光 | 字形边缘内 2–3 px 提亮 #FFF6DA，55% 不透明 |
| 投影 | #331F06 / 60%，偏移 (18,22)，模糊 26 |

金色要亮，别用暗铜色（#A96A12 收尾会显锈）。暗底上五层全上；亮底（CF01、CF05）投影加重到 75%，不然字浮。放大 100% 看字的左下角，能看出厚度和白边才算成立。

## 五、第三层标语（可选）

字高 110，居中，y 随字区下移，白字 + 金色 4 px 描边 + 深棕投影。内容只能取横幅库第 2–8 条（奋战、聚力、抢机遇那几条），不许自编。品牌口号「消费全惠惠，笔笔都实惠」不上封面。

## 六、届号

阿拉伯数字转中文，1–99 覆盖。10 → 第十，19 → 第十九，20 → 第二十，29 → 第二十九届。写错就是错版。
