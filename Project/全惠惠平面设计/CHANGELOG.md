## [2026-10-19] 规划 Agent — 白底事故：补底色块规则 + 新增交付前十条闸门

**触发**：用户看到三张图里有两张糊了一块纯白矩形，判定为不可接受的基础性错误，指出「这么丑的东西怎么能弄上来」「他没有读取技能」。

**根因：规划侧漏写 + 流程缺闸门**

| 环节 | 发生了什么 |
|---|---|
| §4.6 第 3 条（我写的） | 只写「标题压复杂区域就**必须加底色块**」，**没写怎么加** |
| 执行侧 | 照字面做，糊了纯白矩形。它做到了我要求的 |
| 交付前 | **没有自检环节**，做完直接交 |

规则只给了「要做什么」，没给「做成什么样算对」；流程里又没有闸门，错误直接送到用户眼前。

**修复一：§4.6 补「底色块怎么做」**

| 做法 | 判定 |
|---|---|
| 整边渐变蒙版（深红 / 黑 / 米白到透明） | ✅ 首选 |
| 整体压暗或提亮 | ✅ 次选 |
| 版式重构（竖幅色带 / 整块留白 / 上下分层） | ✅ 最稳 |
| 给字加投影或细描边 | ✅ 可用 |
| 纯白 / 纯黑矩形糊在照片上 | ❌ 禁止 |
| 半透明白块无边缘处理 | ❌ 禁止 |

判据：放大看字边缘有没有生硬直边；缩到缩略图这块白会不会抢戏。

**修复二：新增 §4.7 交付前十条打回清单**

云 / 人 / 时段 / 三张差异 / 行业名 / 底色 / 白块 / 缩略图可读 / 编造细节 / 标语溯源。任意一条不过，自己重做。
