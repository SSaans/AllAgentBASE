## [2026-10-19] 规划 Agent — 白底事故：补底色块规则 + 新增交付前十条闸门

**修复一：§4.6 补「底色块怎么做」**

| 做法 | 判定 |
|---|---|

| 版式重构（竖幅色带 / 整块留白 / 上下分层） | ✅ 最稳 |
| 给字加投影或细描边 | ✅ 可用 |
| 纯白 / 纯黑矩形糊在照片上 | ❌ 禁止 |
| 半透明白块无边缘处理 | ❌ 禁止 |

| 深底（红 / 黑 / 深蓝 / 深褐） | 暖白 或 金 |
| 浅底（米 / 白 / 浅灰） | 墨黑 或 深红 |

禁止同色系低对比（深褐压浅褐、深红压砖红、灰字压米底）。

**判据**：缩到手机缩略图大小，标题还能不能一眼读出来。

另加三条：深底浅字或浅底深字二选一不许中间态；标题字重不低于 Bold；不许压在花纹渐变照片上，压了就加底色块。
