> 一句话：给全惠惠这家公司出图、配文案。公司每天要发的东西，这里按时按量做出来。

---

## 一、公司是干什么的

全惠惠。业务有四块：直销、开会讲课、房产、购物平台。

公司有一整套自己的经营理念，写在《全惠惠经营理念框架》里。最上面那句核心理念是八个字：

**全心全意聚商机，互惠互利赢未来**

往下一层是三句话：为消费者省钱、为商家引流、为事业伙伴创造价值。

这套理念就是这个项目写文案的底料。图上写的字，基本都从这儿长出来。

## 二、这个项目要产出什么

**近期最要紧的**：每天发朋友圈，早、中、晚各一张图，各配一段文案。一天出三套。

**往后的**：海报、VIS 形象延展（名片、易拉宝、宣传册这类）、开会讲课用的物料。

**再往后**：需求攒多了，可能会按类型分小类（房产一类、讲课一类这样）。现在先不分，等墙上挂不下了再说。

## 三、给谁看：受众决定怎么画

看图的人里，四十岁以上的占大头，董事长七十多岁。

画的时候记住四条：

- 字要大，一眼能看清，别让人眯着眼认
- 颜色对比要强，红是红，白是白
- 话说得直白，不绕弯，不玩梗，不用网络流行语
- 一张图说清一件事，别塞满

## 四、长什么样：风格基线

**大企业风格。** 稳重、正派、有分量。一看就知道是正规公司出的东西，不是路边小店的传单。

logo 长这样：左边一只红色凤凰，右边毛笔书法写的「全惠惠」三个字，下面一行英文 QUANHUIHUI。

颜色以红、黑、白为主。红取 logo 那种中国红，也可以放宽到正红、朱红；黑用得沉稳；白留出来透气。整体喜庆、大气，有传统底子，同时不显老气。

**现在要的是热烈、有号召力。** 用户看过第一版规整的「企业简报」样式，觉得不够。当前方向是红金配色、带光效、标题做大做足，喊得响。

不碰的东西：荧光色、糖果色、卡通风、网红夸张风、一层叠一层的花哨渐变、四平八稳的公文样式。

## 六、文案怎么写

这一节是重点。图好出，文案是每天的真功夫，也是现在最不到位的地方。

### 6.1 先说调子：现在是百日冲刺

公司当前的主线口号是 **「奋战一百天，冲刺一个亿」**。

所以文案要有那股劲。想想百日誓师大会的场面：台上喊口号，台下几百人一起应，声音是往上走的。要的就是这个感觉。

- **要有气势**。用「奋战」「冲刺」「攻坚」「决战」「必胜」「共赢」这类词，不要温吞水
- **夸张修辞欢迎用**。喊目标、喊决心、把气势写足
- **第一人称**。这是自己在说话，开口就是「我」「我们」。讲的是今天在忙什么、为什么这么拼
- **落点要正**。最后归到公司这边：我们在做什么、能给谁带来什么

⚠️ **夸张归夸张，不许编事实。** 气势上的夸张随便用，凭空编出来的数字、案例、客户评价一律不许写。分界线很简单：喊目标是修辞，编成绩是造假。这条与 `BRD.md` §6.3 红线一致。

### 6.2 金句和口号库：不会写就照抄

**这是硬要求。** 想不出好句子的时候，**直接从下面抄**，一个字都不用改。宁可照抄，不要憋出一句平淡的。

**公司横幅（8 条）**

1. 全心全意聚商机，互惠互利赢未来
2. 奋战一百天，冲刺一个亿
3. 奋战百日不停，业绩再攀高峰
4. 聚力同心作战，百日共铸辉煌
5. 抢抓百日机遇，聚力赢战市场
6. 凝心聚商机，实干创佳绩
7. 全心抢抓商机，百日互惠共赢
8. 团结齐拼搏，携手共辉煌

**小红旗（5 条）**

9. 全力以赴，完成任务
10. 团结聚力，和谐共赢
11. 共建共创，共拓商机
12. 友好协作，互惠共赢
13. 和谐共进，赢取未来

> 这 13 条摘录自 `设计资料/全惠惠横幅及小红旗内容.docx`。用户往那份文件里加了新口号，**以文件为准**，这里只是摘抄。

**理念金句**

| 出处 | 句子 |
|---|---|
| 核心理念 | 全心全意聚商机，互惠互利赢未来 |
| 使命 | 全心全意打造新商业聚合赋能系统，共创共建共享共赢 |
| 愿景 | 为消费者省钱、为商家引流、为事业伙伴创造价值 |
| 价值观 | 利他共生 · 消费有道 · 聚合赋能 · 诚信经营 · 持续增长 |
| 三为方针 | 为消费者省钱 · 为商家引流 · 为事业伙伴创造价值 |

### 6.3 一段文案怎么搭

三句话的事：

1. **一句话打头**，从口号库或理念金句里取，要能当大字往图上放
2. **两三句展开**，说清今天在做什么、这件事为什么值得做
3. **一句收尾**，把劲提起来，或者把公司的态度摆出来

长度八十到一百五十字。短了没劲，长了没人看完。

### 6.4 不能这么写（反例）

下面这些是已经出过的、被用户点名不够格的。别再出现：

| 反例 | 问题在哪 |
|---|---|
| 「今日营业」 | 太平，像贴在卷帘门上的牌子，没有一点劲 |
| 「歇一歇，再出发」 | 泄气。现在是冲刺期，不是休息期 |
| 「祝大家周末愉快」这类打卡问候 | 跟公司要传达的东西没关系 |
| 通篇生活流水账 | 这是给人看你在干什么，不是记日记 |

### 6.5 红线（写之前再看一遍）

- 不承诺收益，不用「稳赚」「保本」「零风险」「一定能赚」
- 不用「最」「第一」「唯一」「国家级」等绝对化用语
- 不编数据、不编案例、不编客户评价
- 不虚构经营事实、不虚构收益、不虚构截止期
- 不夸大效果，不做医疗、保健功效暗示
- 房产类不承诺升值，不做投资回报表述
- 提到「消费权益」时，口径必须跟理念原文一致：权益仅限本人后续消费抵扣使用，不可提现、不可变现、不可转让

直销和房产这两块管得严，一句话说错就出事。

## 七、每天怎么跑：从选题到交件

### 7.1 一天三班

早上、中午、晚上各一轮。每一轮四步：定主题 → 写文案 → 出图 → 交件。

主题由做这件事的人自己按公司经营理念策划。用户点名要做某个主题时，以他点的为准。

**一个提醒**：图和配文是**分开交付**的。整段话不要挤进图里，图上的字要少而大，配文另给一份文字。

### 7.2 成品放在哪、叫什么名

成品统一放到：

```
E:\260930_全惠惠工作合集\261012_平面设计合集\260112_朋友圈成品图与文案
```

下面分三个文件夹，按时段往里放：

```
260112_朋友圈成品图与文案/
├── 早上/
├── 中午/
└── 晚上/
```

**命名格式**（以 10 月 13 日早上第一版为例）：

| 文件 | 名字 |
|---|---|
| 图 | `10月13日早v1.jpg` |
| 文案 | `10月13日早文案v1.txt` |

- 日期写「10月13日」这种写法，不写 20261013
- 时段用**早 / 中 / 晚**一个字，对应各自的文件夹
- 版本号 `v1`、`v2`、`v3`，每次都带上

> 目录名里的 `260112` 是用户给定的，照写，不要自己改。

### 7.3 🔴 一个文件夹里，只有两个文件

**每个时段文件夹里，有且只有两个文件**：当天的图 + 当天的文案 txt。不多不少。

换版的时候：

- 新版本顶替旧版本，文件夹里**只留最新那一版**
- 旧版本别堆在同一个文件夹里，要留档就挪到别处
- 不要出现「图有两个版本、文案只有一个」这种对不上的情况

两个文件的日期、时段、版本号必须**完全对得上**。图叫 `10月13日早v2.jpg`，文案就得叫 `10月13日早文案v2.txt`。

### 7.4 文案 txt 里面长什么样

第一行是固定前缀，**尖括号和冒号都照写**，按时段三选一：

| 文件夹 | 第一行写 |
|---|---|
| `早上/` | `<今日早晨朋友圈文案：>` |
| `中午/` | `<今日中午朋友圈文案：>` |
| `晚上/` | `<今日晚上朋友圈文案：>` |

前缀下面空一行，然后才是正文。

早上这份举例，`10月13日早文案v1.txt` 打开应该长这样：

```
<今日早晨朋友圈文案：>

奋战一百天，冲刺一个亿。今天我们团队又跑了一遍……
```

> 如果这一次还要发到微信群、或用户当场给了别的开头写法，**以用户当次的要求为准**。

### 7.5 交件前自己过一遍

- [ ] 文件夹里就两个文件，日期、时段、版本对得上
- [ ] 图能打开，大字一眼看清，logo 没变形
- [ ] txt 第一行是规定的前缀，尖括号和冒号都在
- [ ] 文案里有口号库或理念里的句子，不是自己憋的大白话
- [ ] 过了 6.5 的红线

## 八、怎么出图、怎么省

出图这活最容易白烧钱：一口气做一堆，然后被推翻，重来。所以工具和纪律要一起定。

### 8.1 本机已经装好的三件家伙

这三个已经装到本机两个技能目录（WorkBuddy 一份、Codex 一份），出图和规划两头都能直接调，不用再去市场找：

```
C:\Users\Unbox\.workbuddy\skills\
C:\Users\Unbox\.codex\skills\
```

| 技能 | 什么时候用 |
|---|---|
| **海报生成器**（`poster-maker`） | **主力出图工具**。本地出图，大字排版、像素精确，自带社媒方图和竖图的尺寸规范与模板，不烧外部接口 |
| **健华朋友圈海报**（`jianhua-moments-poster`） | 借它的**两道确认闸**：先问清今天讲什么，再把图上每一处文字逐条报给用户过目，点头了才出图。另外它带一个去平台角标的脚本，成品图右下角出现「AI生成」字样时用它清掉 |
| **海报传单排版器**（`poster-flier-kit`） | 只出方案不出图。文案分几级、主标副标怎么排、配色怎么配、有没有毛病，卡壳时问它 |

⚠️ **一条边界**：健华那个技能默认走「AI 直接画整张海报」的通道。**本项目不这么用。** 带中文和 logo 的成品一律由程序叠字，AI 只出无字背景。理由简单，图像模型写中文会写错字、画 logo 会走形。

**主力那个怎么调**，以本机受管 Node 为例：

```bash
node "C:\Users\Unbox\.codex\skills\poster-maker\scripts\render.mjs" \
     --html 你的海报.html -o 输出.png --width 1080 --height 1080
```

先写一个 HTML 片段当画布（宽高按目标尺寸设），再让脚本把它渲成 PNG。中文用微软雅黑或黑体都识别得到。首次运行它会自己装一次渲染依赖，之后不用管。

> ✅ **已验证可用**（2026-10-12 实跑）：1080×1080 红金大字图，中文渲染正确、一次成型，无错字无变形。

⚠️ 装的是**本机技能**，仓库里不存副本（第三方包，公开仓库不放）。要重装就在技能市场搜上面三个名字。

### 8.2 省 token 五条（照做）

1. **一次只做一个时段**。出一张，交一张，确认了再进下一张。不要一口气铺三张再一起改
2. **出图前先把文字定死**。文案和图上每一行字都确认过再渲染，不要出完图才发现字要改
3. **模板定了就只换字**。同一套版式反复用，不要每张都重新设计、重新生成背景
4. **改哪儿改哪儿**。用户说标题太大，就只改标题，不要顺手推翻重做
5. **不主动加量**。用户要一张就给一张，不要自作主张多做两版让他挑
