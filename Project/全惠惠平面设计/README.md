## 〇、一句话指令（先看这段）

用户每天只会说一句话：

> **「按照格式，帮我做今天早中晚的一套图加文案」**

这一句就是完整工单。收到之后按下面九步走，**不要回头问用户任何问题**。

### 第 1 步 · 定日期，建文件夹

- 用户说「今天」就取当天日期；说「明天」就取次日；给了具体日期就用他给的
- 都没说，就看成品目录里已有的日期文件夹，**接着最后一天往下排**（最后一个是 `10月14日/`，本次就做 `10月15日/`）
- 实在判断不出来，用当天日期
- 日期写法固定为**「10月13日」**这种，不写 20261013
- 🔴 **每天新建一个以日期命名的文件夹**，当天所有产出都放进它里面。**已有的日期文件夹一律不动**

### 第 2 步 · 定版本号

🔴 **版本号跟日期绑在一起，跨天就归零。** 先看三个文件夹里现有文件名是哪一天，再决定本次用 v 几：

| 文件夹里现有文件 | 本次版本号 |
|---|---|
| 日期和本次**相同**（同一天改稿） | 读出最大 `vN`，本次 `v(N+1)` |
| 日期和本次**不同**（新的一天） | 本次从 **`v1`** 起，不管前一天做到 v 几 |
| 文件夹是空的 | 从 `v1` 起 |

举例：13 日已经交到 `v3`，现在做 14 日的图，就叫 `10月14日早v1.jpg`，**不是 v4**。版本号是「这一天改了几稿」，不是「总共出了几版」。

三个时段的版本号**共用同一个**，不要早上 v1、中午 v2、晚上 v3。

### 第 3 步 · 读规范（只读一遍）

按顺序读这几份，读完就动手，不要反复回来翻：

1. 本文件 **§4.3 到 §4.7 全部**（七条硬规则、三张要拉开、时段符号、文字对比、打回清单）
2. `视觉规范卡.md`（色值、字号、边距这些硬参数）
3. `设计资料/全惠惠横幅及小红旗内容.docx`（口号从这儿取）
4. `参考库\索引.md`（挑风格用，见第 4 步）

### 第 4 步 · 挑风格 ← 今天长什么样，由这一步定

🔴 **一套三张，要挑三个不同编号。** 这是治「每次都是一个样」的关键一步。

打开 `参考库\索引.md`，挑三个：

1. 筛出「状态 = 可用」的风格
2. 按「上次使用」升序排，从没用过的排最前
3. 在前 5 个里挑三个**互不相同**的编号
4. **三张不许同号**，跟上一次那套也尽量错开

挑中三个之后，打开各自的 `风格卡.md`，同时按 §4.4 把三张的**景别**（远 / 中 / 特写）、**主体**（人 / 物 / 空场）、**构图**拉开。

机制细节见 §十。

### 第 5 步 · 定三个主题和角色

**先定角色，再定主题。** 角色决定这话是说给谁听的。

打开 `参考库\角色方向\README.md`，四个角色里挑：

| 编号 | 角色 | 给什么 |
|---|---|---|
| R01 | 消费者 | 给价值 |
| R02 | 实体商家 | 给增量 |
| R03 | 事业伙伴 | 给成长收益 |
| R04 | 平台生态 | 得生态 |

- 当天三个时段**可以共用一个角色**（形成一组），也可以早中晚各分一个
- 定完角色，钻进对应那份文档看「核心概念」和「配图方向」，主题从那儿来

然后再定时段侧重：

| 时段 | 侧重 |
|---|---|
| 早 | 开场、定目标、喊状态 |
| 中 | 保持节奏、跟进落实、鼓劲 |
| 晚 | 复盘、感谢同行、蓄力明天 |

### 第 6 步 · 写三段文案

先按 `参考库\文案素材与洗稿规则.md` 挑标语、定类型，再按 §6.3 的三段式写。**每段 80 字以内**，第一人称，必须有从素材池取来的口号，不许自己编。

### 第 7 步 · 出图（照第 4 步挑中的风格走）

🔴 **文案、底图、排版这三样，每天都重新做。** 风格由第 4 步决定，不凭感觉定。

| 部件 | 怎么办 |
|---|---|
| 风格 | **按第 4 步挑中的那个走**。这是每天最该变的地方 |
| 底图 | 照风格卡里的「出图提示词」重新生成，不带字 |
| 图上文字 | 主标语从素材池取（誓师口径），行业名从产业清单取，卖点一句自写 |
| 排版 | 照风格卡里的「视觉拆解」来，别再用上一天那套版式 |
| 文案 | **全新写**，不许跟前一天重复。三段式格式和语气延续，**80 字以内** |
| 素材 | logo 文件、字体、口号库、理念金句尽管用，这些是共用的本钱 |
| 🔴 品牌底线 | logo 用矢量原稿、标题字要大、底部品牌条照旧。**这几样不随风格变** |

风格换的是**语言**，不是**身份**。再花哨的风格，也得让人一眼看出是全惠惠的东西。

> 只有一种情况是「只改用户点名的地方」：**同一天之内**用户让你改稿。跨了天就是全新的一套。

**出完图，先过 §4.7 的打回清单，十条全过再往下走。** 过不了自己重做，不要交。

### 第 8 步 · 归档

- 当天新建的日期文件夹里，早上 / 中午 / 晚上三个子夹各放两个文件，命名见 §7.2
- 当天文件夹里出现旧版（同一天的改稿），把旧版搬进 `历史归档\<日期>-v<原版本号>\`
- 🔴 **别的日期文件夹一律不许动。** 13 日的就留在 13 日那儿，做 14 日的也不许去碰它
- 移动是**搬家不是删除**，一个都不能丢

### 第 9 步 · 回填参考库，只报一句

回填两处：

- `参考库\索引.md`：把这次的风格编号、日期、累计次数填进「使用记录」表
- 这次自己迭代出的好底图，存一份进那个风格的文件夹，给下次留料

然后说一句就够：「三个时段出一套 vN，用的 SXX，**打回清单十条已过**，已放到位」。**不要贴文件清单，不要贴命令，不要贴路径表。**

## 四、长什么样：风格基线

### 4.1 七个方案，按轮转挑

风格库里现有七个方案，**每次出图按 §〇 第 4 步的轮转规则挑一个**，不再固定用哪一套。

| 编号 | 方案 | 一句话 | 气质 |
|---|---|---|---|
| S01 | 商务实景 | 商务人物站在场景里 | 职业、明亮 |
| S02 | 极简大字 | 没有照片，字就是画面 | 硬、直接 |
| S03 | 国潮纹样 | 红金打底，纹样压阵 | 隆重、仪式感 |
| S04 | 建筑光影 | 只有建筑和光 | 冷、硬、空间感 |
| S05 | 水墨留白 | 宣纸与墨，留白为主 | 静、克制 |
| S06 | 生活器物 | 暖光下的手和物 | 暖、近、有温度 |
| S07 | 城市天际 | 用整座城说话 | 开阔、宏大 |

每个方案的细节、「固定什么 / 自由什么」、适用场景与坑，都在 `参考库\SXX-方案名\风格卡.md` 里。七个方案之间的差异对照表见 `参考库\索引.md` 第一节。

> ⚠️ **旧版本这里写过「不要每天换风格，同一套版式反复用，只换内容」，那句话已经作废。** 它正是十天出图一个样的根源，别再照它做。

### 4.2 大方向不能丢

**大企业风格**，稳重、正派、有分量，一看就知道是正规公司出的东西。

颜色以红、黑、白为主。红取 logo 那种中国红，也可以放宽到正红、朱红；黑用得沉稳；白留出来透气。

不碰的东西：荧光色、糖果色、卡通风、网红夸张风、一层叠一层的花哨渐变、四平八稳的公文简报样式、**拟人化**（把产品画成有表情的角色，不够严肃）。

### 4.3 🔴 七条硬规则（2026-10-17 用户明确，违反即打回）

1. **一个「云」都不许有。** 祥云、云纹、云海、云雾、云彩、云朵、卷云纹，画面里和文案里都不许出现。用户原话：「不要云，一个都不要保留」「搞得一堆云是虚空吗」。
2. **每张图必须有具体主体。** 要么有**人**（职业形象、背影、手部特写都算），要么有**与产品明确相关的实物**（货架、酒瓶、车、家具、果蔬都算）。只允许字和装饰纹样的，不算。
3. **图上三层，全部泛用，一个字都不许带行业。**

   | 层级 | 内容 | 例子 |
   |---|---|---|
   | 主标语（最大字） | 誓师口号，从素材池取 | 奋战一百天 冲刺一个亿 |
   | 中间句（次大） | 一句态度或状态，泛用 | 肯干的人，路越走越宽 |
   | 落点（小字） | 一句号召或短句，泛用 | 跟上节奏，一起往前冲 |

   🔴 **不许出现行业名、品类名、业务细节**（2026-10-19 最终口径）。「连锁商超」「新能源汽车」「聚生鲜日用好物」这类，一个都不许上。

   **缺的那一层不是留空，是换成一句泛用的话。** 三层始终要有，只是每层都说得让人听懂、谁都能用。行业交给画面。

   > 📌 这一条反复过三次：先写行业名 → 全删 → 又加回来。**以本次为准，不要再改回去。**

   🔴 **配文必须泛用**：不许出现任何行业词（车型、充电、货架、宴会厅…），不许出现教人办事的口吻（「围绕…讲明白」「要…」「建议…」）。判断标准：把这条文案发给一个开小饭馆的人，他敢不敢原样转发？
4. **必须有产业信息。** 行业只能从 `参考库\产业清单.md` 那 13 项里挑，图上要能看出这是做什么生意的。
5. **早中晚必须真的不一样。** 换的不只是文案：行业、场景、光线、构图都要有差别。早是开张，中是热闹，晚是收成。
6. **财富感和商业气势要足。** 四五十岁的成功人士看的东西，讲厚重、喜庆、有排场。可用礼炮、金币、红毯、绶带、烟花、金元宝、签约场景、光效。**不许拿云来代替「气势」。**
7. **审美要对人。** 目标读者是四五十岁的生意人，喜欢实在、气派、看得懂。小清新、极简冷淡、杂志风，都不对路。

### 4.4 🔴 三张一套，必须拉开（2026-10-19 用户明确，违反即整组打回）

§4.3 那七条是底线。一套三张还要额外满足下面五条差异，**任意一条不满足，整组打回重做**。

| 维度 | 强制要求 |
|---|---|
| **风格** | 三张必须是**三个不同编号**（S01 / S03 / S04 / S05 / S06 / S07 里挑三个）。**不许一张卡用到底。** |
| **景别** | 三张必须覆盖三种：一张**远景或全景**（看环境）、一张**中景**（看人）、一张**近景或特写**（看物件）。 |
| **主体** | 三张不许雷同。人物群像 / 单人 / 背影 / 手部特写 / 纯物品 / 空场空间，**每种最多用一次**。 |
| **构图** | 不许三张都是「上标语、中场景、下品牌条」。至少一张换：满版出血 / 大面积留白 / 左右分割 / 上下分层。 |
| **产业** | 三张对应三个不同产业（见 §4.3 第 4 条）。 |

#### 一眼打回的三种情况

1. 三张里有两张构图一样
2. 三张里出现两次「两个人站在场景里微笑」
3. 三张用了同一个风格编号

> 用户原话：「很雷同」「一直都是这种两个人加某样东西」「我要的是景别、表达都不一样的」。

#### 景别怎么用（三张摆一起，节奏才对）

| 景别 | 拍什么 | 作用 |
|---|---|---|
| 远景 / 大全景 | 一整条街、一个大堂、一片场地 | 交代格局 |
| 全景 | 人的全身 + 环境 | 交代场景关系 |
| 中景 | 腰部以上 | 看表情、看动作 |
| 近景 | 胸部以上 | 看神态 |
| 特写 | 一双手、一个产品、一个细节 | 讲质感、讲专注 |

推荐节奏：**远景打头 → 中景承接 → 特写收尾**。顺序可调，但三种必须有。

#### 主体怎么换（2026-10-19 二次修正：只有手也不行）

🔴 **「纯物品」「空场空间」「只有一双手」都试过了，全冷，全废掉。** 现在每张都得让人看见人。

| 类型 | 长什么样 | 配什么景别 |
|---|---|---|
| 单人 | 一个人推门进来、站在窗前、在整理货架（**脸要看得见**） | 中景 / 近景 |
| 双人搭把手 | 两个人在递东西、一起抬、一左一右配合 | 中景 |
| 双人近景互动 | 两个人碰杯、敬酒、握手、递名片（**上半身和脸都入镜**） | 近景 / 特写 |
| 群像 | 一群人围坐商量、一起走、一桌人举杯 | 远景 / 全景 |
| 背影 | 一个人走向店门口、走向远处 | 远景 |

**已禁用**：纯物品 · 空场空间 · 只有手没有人的特写。

#### 🔴 判据

**画面里能不能看见人的脸或上半身？只能看见一双手，就是冷的。**

用户原话：「只有个手还是感觉不太好」「要么特写、近景两个人碰杯」「只有手脚或者物品还是太冰冷了」。

#### 三张的配比

远景群像 / 中景双人搭把手 / **近景双人碰杯**。三张都有人，距离和人数不同，景别自然拉开。

### 4.6 🔴 文字必须跳出来（2026-10-19 用户明确）

用户看那套图说：「文字颜色怎么都差不多的，要有对比啊」。

**问题**：标题都是深色压在浅底上，左图和右图尤其闷 —— 深褐字压浅褐底，远看一团。

#### 硬规则

| 底色 | 字色 | 例子 |
|---|---|---|
| 深底（红 / 黑 / 深蓝 / 深褐） | **暖白** 或 **金** | 红底白字、黑底金字 |
| 浅底（米 / 白 / 浅灰） | **墨黑** 或 **深红** | 米底黑字、白底红字 |

**禁止**：同色系低对比（深褐压浅褐、深红压砖红、灰字压米底）。

#### 判据

**把图缩到手机缩略图大小，标题还能不能一眼读出来？** 读不出，对比不够。

#### 三条硬指标

1. 标题与背景**必须深底浅字或浅底深字，二选一，不许中间态**
2. 标题字重不低于 Bold
3. 标题不许压在花纹、渐变、照片的复杂区域

#### 🔴 第 3 条怎么落地（2026-10-19 补：上一版漏写，出了白底事故）

上一版只写了「压了就加底色块」，没写怎么加。执行方直接糊了一块纯白矩形，像贴了张便签。

**底色块只有一个原则：让字像是「长在画面里」，不能像「事后贴上去」。**

| 做法 | 能不能用 | 说明 |
|---|---|---|
| **整边渐变蒙版** | ✅ 首选 | 从画面一侧向内渐变（深红 / 黑 / 米白到透明），字压在渐变的实色端 |
| **整体压暗或提亮** | ✅ 次选 | 整张图统一压一层，不是局部贴块 |
| **版式重构** | ✅ 最稳 | 把文字区做成画面结构的一部分：整条竖幅色带、整块留白、上下分层 |
| **给字加投影或细描边** | ✅ 可用于小字 | 不贴块，靠字的轮廓提对比 |
| **纯白 / 纯黑矩形直接糊在照片上** | ❌ **禁止** | 生硬直边，一看就是贴的，最丑的一种 |
| **半透明白块无边缘处理** | ❌ 禁止 | 一样生硬，只是没那么刺眼 |

#### 判据

**放大看字的边缘：有没有一条生硬的直边？** 有，就是贴上去的，打回。

**缩到缩略图：这块白（或黑）会不会跳出来抢戏？** 会，打回。

#### 🔴 字号必须拉开，不然老年人看不清

三个层级字号差不多，四五十岁的人看就是一团。用户原话：「一堆老年人看的头昏眼花的」。

| 层级 | 1080 宽下的字高 | 与主标语的比例 |
|---|---|---|
| 主标语 | 120–160 px | 1 |
| 中间句 | 56–70 px | 约 1/2.5 |
| 落点 | 40–48 px | 约 1/3 |

**主标语和落点的字号比，至少 3 倍。**

再加四条：

1. 三个层级**字重也要有差**（主标语 Black 或 Bold，落点 Regular）
2. 颜色别三级一样，**至少有一级换色**
3. 层级之间留白不少于 24 px，别挤在一起
4. 主标语行距 1.1–1.2，中间句和落点可以松一点

## 六、文案怎么写

图好出，文案是每天的真功夫。

### 6.1 调子：百日冲刺，但说人话

公司当前的主线是 **「奋战一百天，冲刺一个亿」**。

文案要有那股劲，但不能喊成空洞口号。落地方式是：**嘴里喊口号，手里说具体的事**。口号用来提气，具体的事用来让人信。

- 要有气势，用「奋战」「冲刺」「攻坚」「落实」「共赢」这类词
- 夸张修辞欢迎用，喊目标、喊决心都行
- **第一人称**，开口就是「我」「我们」，讲今天在忙什么
- 最后一定归到公司这边

⚠️ **夸张归夸张，不许编事实。** 气势上的夸张随便用，凭空编出来的数字、案例、客户评价一律不许写。喊目标是修辞，编成绩是造假。这条与 `BRD.md` §6.3 红线一致。

### 6.2 金句和口号库：不会写就照抄

**这是硬要求。** 想不出好句子的时候，**直接从下面抄**，一个字都不用改。宁可照抄，不要憋出一句平淡的。

### 6.3 一段文案的标准结构（80 字内）

🔴 **红线：整段不超过 80 字**（含标点，不含换行和前缀行）。挂朋友圈一屏看完，不用点「全文」。

🔴 **第一条规矩：配文必须泛用，谁都能转发。**

- 配文里**不许出现具体行业词**（车型、充电、宴会厅、货架、生鲜、客房、展厅…）
- **不许出现教人办事的口吻**（「围绕…把…讲明白」「要…」「请…」「建议…」）
- **不许编造具体的行为细节**（「走了两万步」「忙到现在才吃上一口饭」）
- 只干两件事：**鼓励**，或者**宣传**

🔴 **动笔前先做一件事**：打开 `参考库\文案素材与洗稿规则.md`，从素材池挑一条标语（B / F / K 系列），定好类型，再按对应表写。**不许自己编标语。**

**照这个三段式写：**

```
今日早晨朋友圈文案：

早上好，伙伴们！☀️
新的一天，先把状态拿出来。肯干的人，路越走越宽。

消费全惠惠，笔笔都实惠！跟上节奏，一起往前冲！
```

逐段说：

| 段 | 内容 | 字数 |
|---|---|---|
| 1 | 前缀行 `今日早晨朋友圈文案：`，不加尖括号 | 不计入 80 字 |
| 2 | 问候 + emoji + 一句当天的状态或态度 | 15–30 字 |
| 3 | 品牌收尾：`消费全惠惠，笔笔都实惠！` 打头，接一句号召 | 20–30 字 |

- **总共 80 字以内**，超了就砍中间那句
- 段与段之间空一行
- 上面的示例约 58 字，还有余量，可以再加一句

🔴 **品牌口号是硬性要求。** 每份文案的第三段必须以 **`消费全惠惠，笔笔都实惠！`** 开头，少一个字都算不合格。

> 2026-10-26 点名过一次：10月27–29 那六份文案，结尾挂的都是素材池里的其他标语（凝心聚商机、团结聚力、全力以赴…），**一句品牌口号都没有**。

**感叹号怎么用**（2026-10-26 用户明确）

- 品牌口号后面**固定用「！」**，不许用句号
- 一句文案里感叹号 **2–4 个**，不要每句都加
- 陈述句用句号；喊话、号召、口号用感叹号
- 报喜、定目标的句子也可以加，比如「今天，先拿下一个！」

**判据**：通篇句号，读着像述职报告；通篇感叹号，读着像刷屏微商。中间那档才对。

**公司全称怎么用**：

| 场合 | 写什么 |
|---|---|
| 正式物料（名片、海报落款、公文、合同） | **广东全惠惠数字科技有限公司** |
| 朋友圈文案、图上收尾 | 简称「全惠惠」，省字 |

### 6.4 不能这么写（反例）

| 反例 | 问题在哪 |
|---|---|
| 「歇一歇，再出发」 | 泄气。现在是冲刺期，不是休息期 |
| 光甩一句「今日营业」就没下文 | 报个状态就完了，撑不起一条文案。这句可以留，后面得有实事 |
| 「祝大家周末愉快」这类打卡问候 | 跟公司要传达的东西没关系 |
| 通篇生活流水账 | 这是给人看你在干什么，不是记日记 |

### 6.5 红线（写之前再看一遍）

- 不承诺收益，不用「稳赚」「保本」「零风险」「一定能赚」
- 不用「最」「第一」「唯一」「国家级」等绝对化用语
- 不编数据、不编案例、不编客户评价
- 不虚构经营事实、不虚构收益、不虚构截止期
- 不夸大效果，不做医疗、保健功效暗示
- 房产类不承诺升值，不做投资回报表述
- 提到「消费权益」时，口径必须跟理念原文一致：权益仅限本人后续消费抵扣使用，不可提现、不可变现、不可转让

直销和房产这两块管得严，一句话说错就出事。

### 6.6 改稿的规矩

用户 2026-10-12 明确过口径，记死：

- **文案可以重写，但必须延续上面这套格式**。问候、emoji、分段鼓励、品牌收尾这几样是骨架，不能丢
- **不经要求不许改语气**。用户说「把标题换个说法」，就只换标题，不要顺手把整段重写一遍
- **换图上的口号，不等于授权重写配文**。两件事分开
- 用户说「恢复原文」，就老老实实按归档里的原文逐字恢复
- 改完只报改了哪里，不要附上全文让他再读一遍

### 7.2 成品放在哪、叫什么名

### 7.3 🔴 一个文件夹里，只有两个文件

**每个时段子夹里，有且只有两个文件**：当天的图 + 当天的文案 txt。不多不少。

- 当天改稿产生新版本时，先把旧版搬去历史归档，再放新版
- 不要出现「图有两个版本、文案只有一个」这种对不上的情况
- 三个时段的版本号保持一致
- 🔴 **一个日期文件夹只装那一天的东西**。别把别的日期的文件塞进来，也别把当天的文件放进别的日期文件夹

两个文件的日期、时段、版本号必须**完全对得上**。图叫 `10月14日早v2.jpg`，文案就得叫 `10月14日早文案v2.txt`。

### 7.4 文案 txt 里面长什么样

第一行是前缀，按时段三选一，**冒号照写，不加尖括号**：

| 文件夹 | 第一行写 |
|---|---|
| `早上/` | `今日早晨朋友圈文案：` |
| `中午/` | `今日中午朋友圈文案：` |
| `晚上/` | `今日晚上朋友圈文案：` |

前缀下面空一行，然后才是正文。完整样子见 §6.3。

> 用户当次给了别的开头写法，以他当次的为准。

⚠️ **一条边界**：健华那个技能默认走「AI 直接画整张海报」的通道。**本项目不这么用。** 带中文和 logo 的成品一律由程序叠字，AI 只出无字背景。理由简单，图像模型写中文会写错字、画 logo 会走形。

**主力那个怎么调**，以本机受管 Node 为例：

```bash
node "C:\Users\Unbox\.codex\skills\poster-maker\scripts\render.mjs" \
     --html 你的海报.html -o 输出.png --width 1080 --height 1920
```

先写一个 HTML 片段当画布（宽高按目标尺寸设），再让脚本把它渲成 PNG。中文用微软雅黑或黑体都识别得到。首次运行它会自己装一次渲染依赖，之后不用管。

> ✅ **已验证可用**（2026-10-12 实跑）：红底中文大字渲染成功，中文零错字、一次成型。

⚠️ 装的是**本机技能**，仓库里不存副本（第三方包，公开仓库不放）。要重装就在技能市场搜上面三个名字。

### 8.2 省 token 六条（照做）

这条最要紧。用户给过话：**执行方少烧 token，一次做对就行**。

3. **风格由 §〇 第 4 步决定，不是沿用上一次**。省 token 省的是「不返工」，不是「不换风格」
4. **改哪儿改哪儿**。用户说标题太大，就只改标题，不要顺手推翻整张
5. **不主动加量**。做一套就是一套，不要多做两版让他挑
6. **不重复读文件**。规范、口号、模板这一轮读过就记住，不要每次动手前再翻一遍

## 十、设计风格参考机制（2026-10-16 新增）

出图连着 10 天是同一套语言，用户判定「过于同质化」。根子不在执行方，在于手里只有一套语言可选。这一节是备货机制。

### 10.1 参考库在哪

```
E:\260930_全惠惠工作合集\261012_平面设计合集\参考库\
├── README.md            ← 机制与流程全文（动手前必读）
├── 00-检索关键词清单.md   ← 用户拿去搜图用的词
├── 索引.md               ← 风格总表 + 轮转记录（挑风格看这个）
├── _待整理\              ← 新收来的图先丢这儿
└── SXX-风格名\           ← 每个风格一个文件夹，内含 风格卡.md + 参考图
```

### 10.2 怎么用（三步）

1. **挑**：读 `索引.md`，按轮转规则挑一个编号 —— 从没用过的排最前，取前 5 个里随机挑，相邻两次不得同号
2. **读**：打开 `SXX-风格名\风格卡.md`，拿里面的「出图提示词 / 关键词 / 参考图」
3. **回填**：出完图，把使用日期与次数填回 `索引.md`

### 10.3 参考的三种形式，任选或叠加

| 形式 | 从哪来 | 什么时候用 |
|---|---|---|
| 提示词 | 风格卡里的「出图提示词」 | 手上有生图工具，直接照它生成无字背景 |
| 关键词 | 风格卡里的「自行搜参考的关键词」 | 想再找贴合的图，或提示词生成得不理想 |
| 图片 | 风格文件夹里的参考图 | 约束力最强，直接照画面的气质走 |

搜图四个站：花瓣、站酷、百度图片、必应图片。

### 10.4 无限新增怎么走

```
用户按关键词清单搜图 → 丢进 _待整理\
        ↓
规划 Agent 归类 → 编 SXX 号 → 写风格卡 → 更新索引
        ↓
新风格自动进入轮转（没用过，排最前）
        ↓
执行 Agent 按规则挑风格 → 出图 → 回填记录 → 把好底图存进该风格文件夹
        ↓
（执行 Agent 也可自己搜新参考、迭代出新方向，交规划 Agent 编号入库）
        ↓
   回到第一步，库越滚越大
```

加一个风格和加一百个风格，操作一模一样，不需要改任何规范或脚本。

### 10.5 三条纪律

1. **不许随手删风格**：不要了的把状态改 `停用`，编号和文件夹都留着
2. **参考图只在本机用，不进公开仓库**（版权）
3. **风格换语言，不换身份**：logo 矢量原稿、标题要大、底部品牌条照旧

### 10.6 内容指向：角色方向

风格卡管「怎么画」，`参考库\角色方向\` 管「说给谁、给什么」。四份文档对应理念里的三类服务主体加平台自己：

| 编号 | 角色 | 理念里的定位 | 给什么 |
|---|---|---|---|
| R01 | 消费者 | 商业的源头 | 给价值 |
| R02 | 实体商家 | 经济的脊梁 | 给增量 |
| R03 | 事业伙伴 | 生态协同方 | 给成长收益 |
| R04 | 平台生态 | 三方协同的那个场 | 得生态 |

每份含：理念原文依据 / 核心概念 / 情绪基调 / 视觉关键词 / 三条配图立意 / 和风格卡怎么搭 / 容易踩的坑。
