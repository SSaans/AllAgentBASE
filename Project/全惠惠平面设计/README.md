# 全惠惠平面设计 · 这是什么

> 一句话：给全惠惠这家公司出图、配文案。公司每天要发的东西，这里按时按量做出来。

---

## 〇、一句话指令（先看这段）

用户每天只会说一句话：

> **「按照格式，帮我做今天早中晚的一套图加文案」**

这一句就是完整工单。收到之后按下面九步走，**不要回头问用户任何问题**。

### 第 1 步 · 定日期，建文件夹

- 用户说「今天」就取当天日期；说「明天」就取次日；给了具体日期就用他给的
- 都没说，就看成品目录里已有的日期文件夹，**接着最后一天往下排**（最后一个是 `10月14日/`，本次就做 `10月15日/`）
- 实在判断不出来，用当天日期
- 日期写法固定为**「10月13日」**这种，不写 20261013
- 🔴 **每天新建一个以日期命名的文件夹**，当天所有产出都放进它里面。**已有的日期文件夹一律不动**

### 第 2 步 · 定版本号

🔴 **版本号跟日期绑在一起，跨天就归零。** 先看三个文件夹里现有文件名是哪一天，再决定本次用 v 几：

| 文件夹里现有文件 | 本次版本号 |
|---|---|
| 日期和本次**相同**（同一天改稿） | 读出最大 `vN`，本次 `v(N+1)` |
| 日期和本次**不同**（新的一天） | 本次从 **`v1`** 起，不管前一天做到 v 几 |
| 文件夹是空的 | 从 `v1` 起 |

举例：13 日已经交到 `v3`，现在做 14 日的图，就叫 `10月14日早v1.jpg`，**不是 v4**。版本号是「这一天改了几稿」，不是「总共出了几版」。

三个时段的版本号**共用同一个**，不要早上 v1、中午 v2、晚上 v3。

### 第 3 步 · 读规范（只读一遍）

按顺序读这几份，读完就动手，不要反复回来翻：

1. 本文件 §六、§七
2. `视觉规范卡.md`（色值、字号、边距这些硬参数）
3. `设计资料/全惠惠横幅及小红旗内容.docx`（口号从这儿取）
4. `参考库\索引.md`（挑风格用，见第 4 步）

### 第 4 步 · 挑风格 ← 今天长什么样，由这一步定

🔴 **这是治「十天一个样」的关键一步。**

打开 `参考库\索引.md`，按轮转规则挑一个：

1. 筛出「状态 = 可用」的风格
2. 按「上次使用」升序排，从没用过的排最前
3. 取前 5 个，在这几个里随机挑一个
4. **相邻两次不得用同一个编号**

挑中之后，打开对应文件夹里的 `风格卡.md`。卡里的「出图提示词」「关键词」「参考图」三样就是这次的视觉依据。机制细节见 §十。

### 第 5 步 · 定三个主题和角色

**先定角色，再定主题。** 角色决定这话是说给谁听的。

打开 `参考库\角色方向\README.md`，四个角色里挑：

| 编号 | 角色 | 给什么 |
|---|---|---|
| R01 | 消费者 | 给价值 |
| R02 | 实体商家 | 给增量 |
| R03 | 事业伙伴 | 给成长收益 |
| R04 | 平台生态 | 得生态 |

- 当天三个时段**可以共用一个角色**（形成一组），也可以早中晚各分一个
- 定完角色，钻进对应那份文档看「核心概念」和「配图方向」，主题从那儿来

然后再定时段侧重：

| 时段 | 侧重 |
|---|---|
| 早 | 开场、定目标、喊状态 |
| 中 | 保持节奏、跟进落实、鼓劲 |
| 晚 | 复盘、感谢同行、蓄力明天 |

### 第 6 步 · 写三段文案

按 §6.3 的标准结构写，每段 150–200 字，第一人称，含口号库或理念里的句子。

### 第 7 步 · 出图（照第 4 步挑中的风格走）

🔴 **文案、底图、排版这三样，每天都重新做。** 风格由第 4 步决定，不凭感觉定。

| 部件 | 怎么办 |
|---|---|
| 风格 | **按第 4 步挑中的那个走**。这是每天最该变的地方 |
| 底图 | 照风格卡里的「出图提示词」重新生成，不带字 |
| 排版 | 照风格卡里的「视觉拆解」来，别再用上一天那套版式 |
| 文案 | **全新写**，不许跟前一天重复。五段式格式和语气延续，内容重来 |
| 素材 | logo 文件、字体、口号库、理念金句尽管用，这些是共用的本钱 |
| 🔴 品牌底线 | logo 用矢量原稿、标题字要大、底部品牌条照旧。**这几样不随风格变** |

风格换的是**语言**，不是**身份**。再花哨的风格，也得让人一眼看出是全惠惠的东西。

> 只有一种情况是「只改用户点名的地方」：**同一天之内**用户让你改稿。跨了天就是全新的一套。

### 第 8 步 · 归档

- 当天新建的日期文件夹里，早上 / 中午 / 晚上三个子夹各放两个文件，命名见 §7.2
- 当天文件夹里出现旧版（同一天的改稿），把旧版搬进 `历史归档\<日期>-v<原版本号>\`
- 🔴 **别的日期文件夹一律不许动。** 13 日的就留在 13 日那儿，做 14 日的也不许去碰它
- 移动是**搬家不是删除**，一个都不能丢

### 第 9 步 · 回填参考库，只报一句

回填两处：

- `参考库\索引.md`：把这次的风格编号、日期、累计次数填进「使用记录」表
- 这次自己迭代出的好底图，存一份进那个风格的文件夹，给下次留料

然后说一句就够：「三个时段出一套 vN，用的 SXX，已放到位」。**不要贴文件清单，不要贴命令，不要贴路径表。**

---

### 🔴 这条指令里不要做的事

- ❌ 不要问用户「配色用哪套」「标题写什么」——规范里都定死了
- ❌ 不要一口气多出一版让他挑，做一套就是一套
- ❌ **不许动别的日期的文件夹**，也不许把旧日期的成品搬去归档
- ❌ 不要拿上一天的模板套一套就交差，那样不算「重新做一套」
- ❌ 不要跳过第 4 步凭感觉定风格，也不许连着两次用同一个编号
- ❌ 不要把整段配文塞进图里

## 一、公司是干什么的

全惠惠。业务有四块：直销、开会讲课、房产、购物平台。

公司有一整套自己的经营理念，写在《全惠惠经营理念框架》里。最上面那句核心理念是八个字：

**全心全意聚商机，互惠互利赢未来**

往下一层是三句话：为消费者省钱、为商家引流、为事业伙伴创造价值。

这套理念就是这个项目写文案的底料。图上写的字，基本都从这儿长出来。

## 二、这个项目要产出什么

**近期最要紧的**：每天发朋友圈，早、中、晚各一张图，各配一段文案。一天出三套。

**往后的**：海报、VIS 形象延展（名片、易拉宝、宣传册这类）、开会讲课用的物料。

**再往后**：需求攒多了，可能会按类型分小类（房产一类、讲课一类这样）。现在先不分，等墙上挂不下了再说。

## 三、给谁看：受众决定怎么画

看图的人里，四十岁以上的占大头，董事长七十多岁。

画的时候记住四条：

- 字要大，一眼能看清，别让人眯着眼认
- 颜色对比要强，红是红，白是白
- 话说得直白，不绕弯，不玩梗，不用网络流行语
- 一张图说清一件事，别塞满

## 四、长什么样：风格基线

### 4.1 现在在用的这套（照这个做）

用户已经认可的，是**商务实景 + 大字排版**这一路：

| 部件 | 长什么样 |
|---|---|
| 底子 | 白底为主，干净、亮堂 |
| 主图 | 商务人物照（西装、走动或站立、神态自信），占画面右侧或一侧 |
| 标题 | 黑体大字，两行，左侧竖排，字要大要压得住 |
| 副标题 | 红色同样大号字，接在标题下面 |
| 正文 | 黑色小字，一两句短句，左对齐 |
| 强调句 | 红色，收在正文下面 |
| 底部 | 白色横条，左边全惠惠 logo（红凤凰 + 书法字 + QUANHUIHUI），右边红黑两行「全心全意聚商机 / 互惠互利赢未来」 |

红是点缀不是主色，白留得住，整体干净有精神。**不要每天换风格**，同一套版式反复用，只换内容。

### 4.2 大方向不能丢

**大企业风格**，稳重、正派、有分量，一看就知道是正规公司出的东西。

颜色以红、黑、白为主。红取 logo 那种中国红，也可以放宽到正红、朱红；黑用得沉稳；白留出来透气。

不碰的东西：荧光色、糖果色、卡通风、网红夸张风、一层叠一层的花哨渐变、四平八稳的公文简报样式。

## 六、文案怎么写

图好出，文案是每天的真功夫。

### 6.1 调子：百日冲刺，但说人话

公司当前的主线是 **「奋战一百天，冲刺一个亿」**。

文案要有那股劲，但不能喊成空洞口号。落地方式是：**嘴里喊口号，手里说具体的事**。口号用来提气，具体的事用来让人信。

- 要有气势，用「奋战」「冲刺」「攻坚」「落实」「共赢」这类词
- 夸张修辞欢迎用，喊目标、喊决心都行
- **第一人称**，开口就是「我」「我们」，讲今天在忙什么
- 最后一定归到公司这边

⚠️ **夸张归夸张，不许编事实。** 气势上的夸张随便用，凭空编出来的数字、案例、客户评价一律不许写。喊目标是修辞，编成绩是造假。这条与 `BRD.md` §6.3 红线一致。

### 6.2 金句和口号库：不会写就照抄

**这是硬要求。** 想不出好句子的时候，**直接从下面抄**，一个字都不用改。宁可照抄，不要憋出一句平淡的。

**公司横幅（8 条）**

1. 全心全意聚商机，互惠互利赢未来
2. 奋战一百天，冲刺一个亿
3. 奋战百日不停，业绩再攀高峰
4. 聚力同心作战，百日共铸辉煌
5. 抢抓百日机遇，聚力赢战市场
6. 凝心聚商机，实干创佳绩
7. 全心抢抓商机，百日互惠共赢
8. 团结齐拼搏，携手共辉煌

**小红旗（5 条）**

9. 全力以赴，完成任务
10. 团结聚力，和谐共赢
11. 共建共创，共拓商机
12. 友好协作，互惠共赢
13. 和谐共进，赢取未来

> 这 13 条摘录自 `设计资料/全惠惠横幅及小红旗内容.docx`。用户往那份文件里加了新口号，**以文件为准**，这里只是摘抄。

**理念金句**

| 出处 | 句子 |
|---|---|
| 核心理念 | 全心全意聚商机，互惠互利赢未来 |
| 使命 | 全心全意打造新商业聚合赋能系统，共创共建共享共赢 |
| 愿景 | 为消费者省钱、为商家引流、为事业伙伴创造价值 |
| 价值观 | 利他共生 · 消费有道 · 聚合赋能 · 诚信经营 · 持续增长 |
| 三为方针 | 为消费者省钱 · 为商家引流 · 为事业伙伴创造价值 |

### 6.3 一段文案的标准结构

**照这个五段式写**，这是用户认可的样子，不要改结构。

```
今日早晨朋友圈文案：
                     ← 空一行
早上好，伙伴们！☀️
今日营业，热情开场！
                     ← 空一行
把干劲拿出来，把事业做扎实！新的一天，主动沟通、用心服务，
把每一次交流当回事，把每一份信任放在心上。
                     ← 空一行
今天就给自己定一个小目标：推进一件拖着的事，回应一个待解决的
需求。让计划落地，让行动发声！
                     ← 空一行
全惠惠，全心全意聚商机，互惠互利赢未来。带上笑容，拿出状态，
一起出发！
```

逐段说：

| 段 | 内容 | 要求 |
|---|---|---|
| 1 | 前缀行 | `今日早晨朋友圈文案：`，**不加尖括号**。中、晚同理换成中午 / 晚上 |
| 2 | 问候 | 「早上好，伙伴们！」+ emoji（早 ☀️ / 中 ☀️ / 晚 🌙），再补一句当天的状态话 |
| 3 | 正文 | 今天在做什么、为什么值得做，具体动作，第一人称 |
| 4 | 收束 | 给自己定个小目标、把话收到行动上 |
| 5 | 品牌收尾 | `全惠惠，全心全意聚商机，互惠互利赢未来。` 打头，后面接一句号召或祝福 |

- **总长 150–200 字**，超过 200 字就砍中间那段
- 段与段之间空一行，好读
- 第 2、5 段是固定的骨架，第 3、4 段是每天变的内容

### 6.4 不能这么写（反例）

| 反例 | 问题在哪 |
|---|---|
| 「歇一歇，再出发」 | 泄气。现在是冲刺期，不是休息期 |
| 光甩一句「今日营业」就没下文 | 报个状态就完了，撑不起一条文案。这句可以留，后面得有实事 |
| 「祝大家周末愉快」这类打卡问候 | 跟公司要传达的东西没关系 |
| 通篇生活流水账 | 这是给人看你在干什么，不是记日记 |

### 6.5 红线（写之前再看一遍）

- 不承诺收益，不用「稳赚」「保本」「零风险」「一定能赚」
- 不用「最」「第一」「唯一」「国家级」等绝对化用语
- 不编数据、不编案例、不编客户评价
- 不虚构经营事实、不虚构收益、不虚构截止期
- 不夸大效果，不做医疗、保健功效暗示
- 房产类不承诺升值，不做投资回报表述
- 提到「消费权益」时，口径必须跟理念原文一致：权益仅限本人后续消费抵扣使用，不可提现、不可变现、不可转让

直销和房产这两块管得严，一句话说错就出事。

### 6.6 改稿的规矩

用户 2026-10-12 明确过口径，记死：

- **文案可以重写，但必须延续上面这套格式**。问候、emoji、分段鼓励、品牌收尾这几样是骨架，不能丢
- **不经要求不许改语气**。用户说「把标题换个说法」，就只换标题，不要顺手把整段重写一遍
- **换图上的口号，不等于授权重写配文**。两件事分开
- 用户说「恢复原文」，就老老实实按归档里的原文逐字恢复
- 改完只报改了哪里，不要附上全文让他再读一遍

## 七、每天怎么跑：从选题到交件

### 7.1 一天三班

早上、中午、晚上各一轮。每一轮四步：定主题 → 写文案 → 出图 → 交件。

主题由做这件事的人自己按公司经营理念策划。用户点名要做某个主题时，以他点的为准。

**一个提醒**：图和配文是**分开交付**的。整段话不要挤进图里，图上的字要少而大，配文另给一份文字。

### 7.2 成品放在哪、叫什么名

成品统一放到：

```
E:\260930_全惠惠工作合集\261012_平面设计合集\260112_朋友圈成品图与文案
```

🔴 **每天新建一个以日期命名的文件夹**，里面再按时段分三个子夹：

```
260112_朋友圈成品图与文案/
├── 早上/          ← 10月13日那一套，原地保留，不许动
├── 中午/
├── 晚上/
└── 10月14日/      ← 从 14 日起，每天新建一个这样的文件夹
    ├── 早上/
    ├── 中午/
    └── 晚上/
```

- 10月13日 那套现在直接放在根下的三个时段夹里，**保持原样**，不要移动、不要重命名、不要搬去归档
- 从 10月14日 开始，每天的产出放进自己那个日期文件夹
- 每个时段子夹里，仍然只有两个文件

**命名格式**（以 10 月 14 日早上为例）：

| 文件 | 名字 |
|---|---|
| 图 | `10月14日早v1.jpg` |
| 文案 | `10月14日早文案v1.txt` |

- 日期写「10月14日」这种写法，不写 20261014
- 时段用**早 / 中 / 晚**一个字，对应各自的子夹
- 版本号 `v1`、`v2`、`v3`，每次都带上
- 文件名里的日期，必须和所在日期文件夹的日期一致
- 🔴 **新的一天从 `v1` 起**，不要接着前一天往上加。算法见 §〇 第 2 步

**当天改稿**（同一天的旧版）搬到：

```
E:\260930_全惠惠工作合集\261012_平面设计合集\历史归档\10月14日-v1\
```

里面同样分早上 / 中午 / 晚上三个子夹。搬，不是删。

> 目录名里的 `260112` 是用户给定的，照写，不要自己改。

### 7.3 🔴 一个文件夹里，只有两个文件

**每个时段子夹里，有且只有两个文件**：当天的图 + 当天的文案 txt。不多不少。

- 当天改稿产生新版本时，先把旧版搬去历史归档，再放新版
- 不要出现「图有两个版本、文案只有一个」这种对不上的情况
- 三个时段的版本号保持一致
- 🔴 **一个日期文件夹只装那一天的东西**。别把别的日期的文件塞进来，也别把当天的文件放进别的日期文件夹

两个文件的日期、时段、版本号必须**完全对得上**。图叫 `10月14日早v2.jpg`，文案就得叫 `10月14日早文案v2.txt`。

### 7.4 文案 txt 里面长什么样

第一行是前缀，按时段三选一，**冒号照写，不加尖括号**：

| 文件夹 | 第一行写 |
|---|---|
| `早上/` | `今日早晨朋友圈文案：` |
| `中午/` | `今日中午朋友圈文案：` |
| `晚上/` | `今日晚上朋友圈文案：` |

前缀下面空一行，然后才是正文。完整样子见 §6.3。

> 用户当次给了别的开头写法，以他当次的为准。

## 十、设计风格参考机制（2026-10-16 新增）

出图连着 10 天是同一套语言，用户判定「过于同质化」。根子不在执行方，在于手里只有一套语言可选。这一节是备货机制。

### 10.1 参考库在哪

```
E:\260930_全惠惠工作合集\261012_平面设计合集\参考库\
├── README.md            ← 机制与流程全文（动手前必读）
├── 00-检索关键词清单.md   ← 用户拿去搜图用的词
├── 索引.md               ← 风格总表 + 轮转记录（挑风格看这个）
├── _待整理\              ← 新收来的图先丢这儿
└── SXX-风格名\           ← 每个风格一个文件夹，内含 风格卡.md + 参考图
```

### 10.2 怎么用（三步）

1. **挑**：读 `索引.md`，按轮转规则挑一个编号 —— 从没用过的排最前，取前 5 个里随机挑，相邻两次不得同号
2. **读**：打开 `SXX-风格名\风格卡.md`，拿里面的「出图提示词 / 关键词 / 参考图」
3. **回填**：出完图，把使用日期与次数填回 `索引.md`

### 10.3 参考的三种形式，任选或叠加

| 形式 | 从哪来 | 什么时候用 |
|---|---|---|
| 提示词 | 风格卡里的「出图提示词」 | 手上有生图工具，直接照它生成无字背景 |
| 关键词 | 风格卡里的「自行搜参考的关键词」 | 想再找贴合的图，或提示词生成得不理想 |
| 图片 | 风格文件夹里的参考图 | 约束力最强，直接照画面的气质走 |

搜图四个站：花瓣、站酷、百度图片、必应图片。

### 10.4 无限新增怎么走

```
用户按关键词清单搜图 → 丢进 _待整理\
        ↓
规划 Agent 归类 → 编 SXX 号 → 写风格卡 → 更新索引
        ↓
新风格自动进入轮转（没用过，排最前）
        ↓
执行 Agent 按规则挑风格 → 出图 → 回填记录 → 把好底图存进该风格文件夹
        ↓
（执行 Agent 也可自己搜新参考、迭代出新方向，交规划 Agent 编号入库）
        ↓
   回到第一步，库越滚越大
```

加一个风格和加一百个风格，操作一模一样，不需要改任何规范或脚本。

### 10.5 三条纪律

1. **不许随手删风格**：不要了的把状态改 `停用`，编号和文件夹都留着
2. **参考图只在本机用，不进公开仓库**（版权）
3. **风格换语言，不换身份**：logo 矢量原稿、标题要大、底部品牌条照旧
