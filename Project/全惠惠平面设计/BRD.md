## 三、视觉基线（VIS 要点）

> 以下为**规划口径**，执行方需据此产出可落地的《视觉规范卡》，并把精确数值实测后回填（见 `Task.md` 任务 1）。

### 3.1 Logo 使用

- **来源**：只用 `设计资料/全惠惠logo(1).pdf`，任何情况下不得用截图、不得重绘、不得拉伸变形
- **形态**：红色凤凰图形 + 书法体中文「全惠惠」+ 英文 QUANHUIHUI
- **用法**：完整组合优先；空间局促时可用图形部分做小尺寸标记，但须先定比例规则
- **安全边距**：logo 四周留白不少于字高的 1/2

### 3.2 色彩

| 角色 | 说明 |
|---|---|
| 主色 | logo 的中国红（精确色值以原稿实测为准，参考区间 `#C8102E` – `#D02B25`） |
| 辅色 | 黑（沉稳，用于正文与标题）、白（留白与底） |
| 点缀 | 金（节庆、颁奖、年度主题可用，不作日常主色） |
| 禁忌 | 荧光色、糖果色、低对比灰、大面积渐变堆叠、与主流色抢戏的第四种颜色 |

### 3.3 字体

- **标题**：可呼应 logo 的书法气质，用稳重的中文宋体或书法体
- **正文**：无衬线黑体，大字号，字重偏粗
- 🔴 **授权红线**：**只用免费可商用字体**（如思源黑体 / 思源宋体 / 阿里巴巴普惠体 / 站酷系列等）。任何需要购买授权的字体一律不准出现在成品里。字体清单须在《视觉规范卡》中列明并注明许可

### 3.4 版式

- 大标题 + 少量正文 + logo + 落款（公司名 / 部门 / 日期）
- 留白要够，宁可少放
- 视觉重心明确，一眼知道先看哪儿
- 竖版为主（朋友圈沉浸式浏览），必要时方版

### 3.5 尺寸基线

| 用途 | 默认尺寸 |
|---|---|
| 朋友圈单图 | 1080 × 1080（1:1，展示最完整） |
| 朋友圈长图文 | 1080 × 1440（3:4） |
| 海报（中期） | 1080 × 1920（9:16）或按使用场景另定 |

## 五、技术方案（出图管线）

> 规划建议，具体实现由执行方定；下表用于说明「为什么这么走」。

### 5.1 三条路线对比

| 路线 | 做法 | 优点 | 致命短板 |
|---|---|---|---|
| A 纯 AI 生图 | 全图交给图像模型 | 视觉丰富、出得快 | **汉字会画错、logo 会变形、每次不一致** |
| B 模板拼版 | 程序把 logo / 标题 / 文案拼成成品 | 字 100% 准、色值尺寸可控、可批量、可复现 | 视觉丰富度取决于模板质量 |
| C 混合（**推荐**） | AI 出**无字背景**，程序叠 logo 与文字层 | 兼具品牌准确与视觉丰富 | 流程稍长，需维护背景素材库 |

**结论：以 C 为主，B 兜底。** 纯色或几何背景足够时直接走 B，不必调 AI。任何需要出字的成品，文字层一律由程序叠加，**不得让图像模型直接画中文**。

### 5.2 管线构成（建议）

1. **素材层**：logo（从 PDF 提取为透明底矢量 / 高清位图）、字体文件、背景素材库、图标元素
2. **模板层**：参数化模板（主题 / 标题 / 正文 / 落款 / 配色变体可替换）。早中晚各一套视觉基调
3. **渲染层**：模板 → 成品图（建议 HTML/CSS + 无头浏览器截图，或 SVG 渲染；两者都能保证文字精确与排版一致）
4. **文案层**：理念金句池 + 生成规则 + 合规词表
5. **归档层**：按日期与时段落库，成品、文案、所用模板与素材一并留档

### 5.3 输出规格

- 格式：PNG（优先）/ JPG
- 色彩：屏幕用 sRGB
- 体积：单图控制在社交平台友好区间（一般 2 MB 内）
- 命名：`YYYYMMDD-早/中/晚-主题关键词`

## 六、文案规范与合规红线

### 6.1 取材

理念文本中的五个可用池：

1. 核心理念：全心全意聚商机，互惠互利赢未来
2. 三为方针：为消费者省钱 / 为商家引流 / 为事业伙伴创造价值
3. 使命：全心全意打造新商业聚合赋能系统，共创共建共享共赢
4. 五条价值观：利他共生、消费有道、聚合赋能、诚信经营、持续增长
5. 5W1H 六问：为谁做 / 做什么 / 为什么做 / 何时做 / 在哪做 / 如何做

### 6.2 写法

一段人话，两三句到四五句。先立一个点，再说清楚，最后落到一个行动或态度上。可以引用理念原话，不整段照搬，不堆术语。

### 6.3 🔴 合规红线（直销与房产敏感，逐条执行）

- 不承诺收益，不用「稳赚」「保本」「零风险」「一定能赚」
- 不用「最」「第一」「唯一」「国家级」等绝对化用语
- 不编数据、不编案例、不编客户评价
- 不夸大效果，不做医疗、保健功效暗示
- 房产类不承诺升值，不做投资回报表述
- 涉及「消费权益」的表述，须与理念原文一致：权益仅限本人后续消费抵扣使用，不可提现、不可变现、不可转让

> 建议执行方把上述红线做成**词表过滤**，文案定稿前机器扫一遍，命中即拦。

## 二十、不许编造行为细节（2026-10-17 用户当轮纠正）
