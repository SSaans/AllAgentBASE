# 出图运行说明

## 路径
- 本机运行目录：`H:\Program\全惠惠平面设计`（以以下命令中的实际路径为准）。
- 原始设计资料仅按绝对路径读取；字体使用本机 Noto Sans SC，不分发字体。
- 成品同时交付到 `E:\260930_全惠惠工作合集\261012_平面设计合集\成品\20261012`。

## 复用命令
```powershell
& 'C:\Users\Unbox\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' 'H:\Program\全惠惠平面设计\render.py' --content 'H:\Program\全惠惠平面设计\content.json' --out 'H:\Program\全惠惠平面设计\20261012'
```

依赖 Pillow 与 pypdfium2，使用 Codex 已配置的工作区运行时。无需安装新库。

## 输入与输出
编辑 content.json 的日期、时段、主题、两行标题、正文、问候与配文，再运行命令。每组得到 PNG 与同名 TXT；同时输出三图预览与自测记录。版式当前为纯色几何模板，AI 背景尚未接入。

可选字段 footer 设置落款；red、black、white 设置规范内的配色变体，不改代码。改变标题长度后必须重新查看成品，不仅依赖边界断言。新增日期使用独立输出目录；同日修订应另存版本，避免覆盖已采用的成品。
