# 提案

## Why

表情包散在几个平台里，导不出来也搬不过去。BRD 写了五百多行，包结构、适配器契约、五阶段同步引擎都在，但「什么算同步成功、失败怎么回滚」没有一个能直接照着验的说法。

## What Changes

拆成三个能力，每条配场景。包结构与接口契约留在 README 与代码注释里。

- 导出：把平台里的表情包取出来
- 封装：转成统一的包格式
- 导入：写进目标平台，失败可回滚

## Capabilities

### New Capabilities

- `导出`: 从来源平台读取表情包并落成本地文件
- `封装`: 统一包格式与清单文件的结构
- `导入`: 写入目标平台的流程、校验与回滚

### Modified Capabilities

无，首次建立基线。

## Impact

- `BRD.md` 退役，行为进 `openspec/specs/`
- 接口契约与包结构保留在 README
