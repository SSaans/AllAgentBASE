## 0. 开工前必读（省钱的硬规矩，2026-10-28 用户实测后加）

**实测**：这个会话 1 小时 11 分烧了 $68.82。账单里每一次请求都在**写 7–10 万 token 的缓存**，
一次就是八毛到一块一。原因不是上下文长，是**工具调用太碎**：一次 Bash 只干一件事，
接着 Read 一个文件，再 Bash 一下，每一下都要重写一遍缓存。

**三条硬规矩**

1. **命令能合并就合并。** 一次 Bash 把要查的全查完（`&&` 串起来），不要一个命令一次调用。
   查五个东西，一条命令搞定，不要五条。
2. **不要整读文件。** 先 `grep` 拿行号，再 `sed -n 'A,Bp'` 取那几行。整读一次几千行，
   既费钱又把没用的东西塞进上下文。
3. **一个功能点从头做到能自测为止**，中间不停下来问「要不要继续」。

**开工第一件事**：读 `skill/token节省/SKILL.md`。AGENTS.md 里写它是强制的，
路由表第一条就是它。这次一条没执行，钱就是这么飞的。
