# 学习打卡

群学习打卡计时器，支持关键词归类统计、今日/本周/总时长查询、180分钟硬停、时长门槛过滤。

## 它能干什么

- 记录群成员学习时长，按关键词分类统计
- 5分钟门槛：低于5分钟不计入统计
- 180分钟硬停：超过上限自动结束并提醒
- 暂停/继续：中途暂停，时间不走，继续后恢复计时
- 放弃学习：提前结束且不计入统计
- 休息模式：休息5/15/30分钟，期间不能开始新学习
- 关键词归类：别名映射，统一统计（如py→Python）
- 多维度查询：今日/本周/总时长
- 超时提醒：超过计划时长10分钟后提醒
- 管理员工具：修改技能名、调整今日时长

## 怎么用

### 基础用法（群聊，不需要@）

```text
我要学习Python 30分钟      ← 开始计时
学完了                      ← 结束计时
暂停学习                    ← 暂停计时（时间不走）
继续学习                    ← 继续计时
不学了                      ← 放弃本次学习（不计入统计）
休息5                       ← 休息5分钟（可选5/15/30）
今日学习时长                ← 查看今天学了什么
本周学习时长                ← 查看本周每天时长
总学习时长                  ← 查看所有时间的学习记录
打卡说明                    ← 显示使用帮助
```

**查询他人**（后面加名字或QQ号）：

```text
今日学习时长 张三
总学习时长 1234567890
```

### 管理员专用

```text
修改技能 py改为Python       ← 将"py"归类到"Python"
修改今日时长 Python 30分钟  ← 手动添加今日时长
```

## 触发规则

- **不需要@机器人**，整句匹配触发词即可
- 开始学习格式：`触发词 + 内容 + 数字 + 分钟`
- 所有触发词可在WebUI配置页自定义

## 时长规则

| 规则 | 说明 |
|------|------|
| 最小5分钟 | 低于5分钟不计入统计，会提示"不到5分钟，将不计入时长" |
| 最大180分钟 | 超过180分钟自动结束并提醒休息 |
| 超时提醒 | 超过计划时长10分钟后发送提醒（可配置） |

## 关键词归类

在WebUI配置"关键词别名映射"，格式：

```text
py => Python
java => Java
js => JavaScript
前端 => 前端开发
```

归类后，"py"和"Python"会统计到同一个关键词下。

## 数据存储

- 位置：`core/data/plugin_data/astrbot_plugin_liflag/study.sqlite3`
- 群间隔离：不同群的数据互不干扰
- 持久化：重启后数据保留

## 配置项

在AstrBot WebUI → 插件 → 学习打卡 → 配置页面可调整：

- 所有触发词（开始/结束/查询/说明/管理）
- 时长范围（最小5分钟，最大180分钟）
- 所有回复文案
- 关键词别名映射
- 榜单显示条数

## 常见问题

**Q：为什么我说"学完了"没反应？**  
A：必须先开始学习才能结束。如果没有进行中的学习，"学完了"会静默忽略。

**Q：如何修改所有文案？**  
A：在WebUI配置页面，所有回复文案都可以自定义，支持变量替换（如`{name}` `{minutes}`）。

**Q：别名映射会改历史数据吗？**  
A：不会。别名映射只影响查询时的归类显示，原始数据保持不变。

**Q：管理员命令需要@吗？**  
A：不需要，所有命令都是整句匹配，不需要@机器人。

## 技术细节

- 数据库：SQLite3，自动迁移schema
- 并发控制：asyncio.Lock保护数据库操作
- 轮询检测：每10秒检查硬停和超时提醒
- 群成员解析：通过OneBot API查询群成员列表
