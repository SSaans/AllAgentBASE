🛡️超级管理员

超级管理员拥有所有权限，包括增删普通管理员。每行一个QQ号。

👥管理员名单

普通管理员可以修改时长和技能名，但不能增删管理员

🔧管理员触发词

格式: 修改技能 Python改为py
格式: 修改今日时长 Python 10分钟
格式: 修改本周时长 Python 30分钟
格式: 修改总时长 Python 100分钟
格式: 添加管理员 2403232967
格式: 删除管理员 2403232967
格式: 管理员名单
