## 开发阶段（按序执行）

- [ ] 任务 1：基线验证——确认 astrbot 双进程正常、与 SnowLuma 连接正常、群内普通聊天回复正常；开启 `log_file_enable=true` 并确认日志落盘（改 `cmd_config.json`）
- [ ] 任务 2：插件命令链路实测——群内以 `/` 前缀依次触发 `/群分析`、`/群漫画`、`/分析设置` 等，记录每个指令的响应/报错；确认空 id 白名单语义（普通群友能否触发），必要时调整 `id_whitelist` 或权限配置
- [ ] 任务 3：群分析插件 LLM 连通——实测 `/群分析` 是否调用 LLM 产出报告；若 `llm_provider_id=""` 导致失败，配置为可用 provider（如 `claude-opus-5/claude-opus-5`）并复测
- [ ] 任务 4：群总结内容验收——消息量达标群内 `/群分析` 产出完整报告（话题/称号/金句/锐评，image+text 正常展示），并确认报告以丛雨人设口吻撰写（`keep_original_persona=false` 时提示词自带人设视角要求，需实测确认）
- [ ] 任务 5：转发聊天记录长短分流——实测 LLM 回复超 `forward_threshold`（当前 1500）时自动转合并转发卡片、短回复直接发送；由用户定义长短标准数值后调整并验证生效（无需重启）
- [ ] 任务 6：边界与异常——消息量不足时的提示、无权限时的提示、转发失败时日志可查；汇总运行目录改动摘要落库本仓库
