# 虚拟主播封面设计 · 这是什么

给两位虚拟主播做视频封面。一张封面配一个视频，横屏。

服务对象：柊優花、東雲はる。两人是声优、歌手、主播，形象在 2D 与实写之间来回。

## 产出什么

先 1920×1080 横屏 PNG，后续转 2400×1800 的 4:3 横屏，两版成对交付。

骨架固定：背景强虚化，人物抠图带白边贴上去，超大粗圆体标题带白描边与渐变，几件贴纸点题。字是从标题里炼出来的钩子短语，四到八字，不照抄标题。

## 怎么开工

1. 读 `openspec/specs/` 下四本规格，规矩都在那儿
2. 读 `主体档案/` 里对应那位的档案，名字写法照抄
3. 读工作目录 `风格库\索引.md`，按轮转规则挑一套，再读那套的 `风格卡.md`
4. 照 `openspec/changes/` 里在跑的改动做

## 两段式

先出无字底图，存档；再叠文字。底图独立，换底图不用重排字，改字不用重出底图。

## 尺寸怎么过渡

出 16:9 时心里先套一个居中 4:3 框，主体和字都落在框内。转 4:3 时只换画布与底图，版式判据不动。

## 别和别的项目混

会议封面的规矩在另一个子项目，那套的配色、口号、行业词与文案骨架不适用于这里，也不往本项目文件里带。
