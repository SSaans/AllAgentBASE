# 规格变更：视频转写

## Purpose

规定从视频到文字这条链路的输出形态，让后续摘要与翻译有稳定的输入。

## ADDED Requirements

### Requirement: 转写结果带时间戳

系统 SHALL 输出带时间戳的转写文本，便于定位原片位置。

#### Scenario: 转写一个视频

- **WHEN** 输入一个视频文件
- **THEN** 系统输出逐段文字，每段带起始时间

#### Scenario: 音轨缺失

- **WHEN** 视频没有音轨
- **THEN** 系统 SHALL 明确报错说明原因，不产出空文件

### Requirement: 长视频可分段处理

系统 SHALL 支持超长视频的分段转写，最终合并成一份完整结果。

#### Scenario: 两小时的视频

- **WHEN** 视频时长超出单次处理上限
- **THEN** 系统分段处理后合并，时间戳保持连续
