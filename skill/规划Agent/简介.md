# 规划 Agent 执行卡

AllAgentBASE 多 Agent 接力流程中「规划 Agent」这一棒的**可执行摘要**。

## 这是什么

把 `agents/规划.md`（规划 Agent 操作手册）提炼成一张能直接照做的执行卡：触发条件、职责边界、开工输入、六步可复用流程、交付物、红线、收工自检。

## 什么时候用

用户说「你是规划 Agent」「按 openspec 规范规划审阅」「补充/修订规格」「立 change」「给 XX 立项」「规划一个项目」「勘误过期文档」时。

**不适用**：写功能代码、跑验收出结论（都交开发 Agent）。

## 一句话职责

审阅需求与代码 → 补充/修订 `openspec/specs/` → 规划技术方案 → 评估完成度 → 维护 change 的四件套；**不写功能代码、不执行测试、不处置用户文件**。

## 关键约束（最容易踩的）

- **验收结论归开发写**，规划 Agent 不得替开发宣布完成，也不得自己签
- **规格没场景等于没写**：每条 Requirement 至少配一个 WHEN/THEN
- 收工三件套：四件套齐 + `validate --strict` 通过 + commit & push，缺一不算完工

## 权威来源

- `AGENTS.md` — 角色职责与红线
- `agents/规划.md` — 规划 Agent 操作手册（完整版，与本卡冲突时以它为准）
- `openspec/specs/` — 需求唯一真相来源
