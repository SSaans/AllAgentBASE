多Agent接力工作流 + GitHub同步

同一个项目文件夹、同一套材料（代码 + BRD + 变更日志），不同Agent分工协作，接力传递而非同时修改。

单一代码库 读后写协议 分工不并行 全程留痕

🚀 快速开始

1bash setup.sh https://github.com/你的用户名/仓库名.git — 初始化Git + 连接GitHub
2填写 BRD.md — 定义项目需求和任务排序
3让规划Agent审阅代码 → 更新BRD → 记录CHANGELOG
4让开发Agent根据BRD写代码 → 记录CHANGELOG → git push
5让测试Agent验证功能 → 修Bug → 记录CHANGELOG → git push
01 整体架构

GitHub作为中央仓库，所有Agent围绕同一个项目文件夹接力工作。每个Agent完成自己的任务后提交到Git，下一个Agent从最新代码开始。

02 五大核心原则

这不是"多个Agent同时乱改"，而是"同一个文件夹、同一套材料、不同阶段、分工协作"。

📁

单一代码库

所有Agent围绕同一个项目文件夹，不拆分副本

📖

读后写

动手前必须读代码 + BRD + 变更日志

🔗

分工不并行

规划→开发→测试，接力传递，不同时改

📝

全程留痕

每次修改记录CHANGELOG，写清改了什么

🚫

不越权

测试不改需求，开发不改BRD，各司其职

03 Agent角色定义

三个Agent各司其职，通过BRD和CHANGELOG传递上下文。

📋

规划Agent

Product Manager
  • 审阅现有代码，理解项目运行方式
  • 结合用户想法，补充缺失需求
  • 整理需求到BRD，标注优先级
  • 规划任务执行顺序
  • 更新CHANGELOG记录BRD变更
禁止：不写实现代码
💻

开发Agent

Developer
  • 读BRD理解要做什么
  • 读CHANGELOG了解之前改了什么
  • 读现有代码理解结构
  • 写代码实现需求
  • 自测后更新CHANGELOG
禁止：不改BRD（需求变更找规划Agent）
🧪

测试Agent

QA Engineer
  • 读BRD的验收标准
  • 读CHANGELOG了解最新改动
  • 运行功能测试对比标准
  • 发现Bug修复并记录
  • 回归测试确保旧功能正常
禁止：不改BRD，不加新功能
04 接力工作流

用户提需求后，Agent按规划→开发→测试的顺序接力工作，每轮结束后git push同步到GitHub。

1

规划Agent：需求分析 + 更新BRD

审阅现有代码，结合用户想法补充需求，整理成BRD并标注优先级和依赖关系，规划任务排序。

BRD.mdCHANGELOG.md
2

开发Agent：读BRD + 写代码

先读BRD和CHANGELOG了解上下文，再读现有代码理解结构，然后写代码实现需求，自测后记录CHANGELOG。

源代码CHANGELOG.md
3

开发Agent：git commit + push

开发完成后提交代码到Git并推送到GitHub，保持远程仓库同步。

git commitgit push
4

测试Agent：功能验证 + 修Bug

读BRD验收标准和CHANGELOG最新改动，运行测试，发现Bug修复，回归测试确保旧功能没被改坏。

测试代码CHANGELOG.mdgit push
5

循环：回到规划Agent进入下一轮迭代

用户提出新需求或测试发现问题后，回到规划Agent，开始新一轮接力。每次新一轮开始前先 git pull 拉取最新代码。

git pullBRD.md
05 项目文件说明

模板包含以下文件，每个文件有明确的维护责任人和用途。

文件 用途 谁维护
BRD.md 业务需求文档，所有需求的唯一真相来源 规划Agent
CHANGELOG.md 变更日志，记录每次改了什么、为什么改、影响范围 每个Agent
AGENTS.md Agent角色定义与工作流规范 人类（你）
README.md 项目说明和快速开始指南 人类（你）
.gitignore Git忽略规则（node_modules、构建产物等） 人类（你）
setup.sh Git/GitHub同步初始化脚本 一次性运行
06 Agent交接检查清单

下一个Agent上岗前，确认以下所有项目，避免遗漏或影响旧功能。

我已读完 BRD.md 全文
我已读完 CHANGELOG.md 最新3条记录
我已浏览项目代码结构，了解当前实现
我清楚自己的角色和职责边界
我知道哪些文件我能改、哪些不能碰
我已完成 git pull 拉取最新代码
07 初始化命令

将项目模板复制到你的项目目录，然后运行初始化脚本。

# 1. 复制模板到你的项目目录 cp -r multi-agent-workflow/ /your/project/path/ # 2. 进入项目目录 cd /your/project/path/ # 3. 初始化Git + 连接GitHub（在 github.com/new 创建空仓库） bash setup.sh https://github.com/用户名/仓库名.git # 4. 之后每次Agent完成工作后 git add -A git commit -m "feat: 描述你做了什么" git push # 5. 下一轮开始前先拉取最新 git pull
